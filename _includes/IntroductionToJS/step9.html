Operands are symbols used to manipulate a specific value or operand in JavaScript. These symbols are known as operands. A variety of mathematical and logical operations are carried out on operands by means of operators. In other terms, an operator can be said to operate the operands. Operators are used in JavaScript to execute operations such as arithmetic and value comparisons.


JavaScript Operators: JavaScript supports a number of operators:


  • Arithmetic Operators
  • Assignment Operators
  • Comparison Operators
  • Logical Operators
  • Ternary Operators
  • typeof Operator

Arithmetic Operators

A character that completes a task in our code is called an operator. We can conduct math calculations on numbers using the built-in arithmetic operators of JavaScript. These consist of the following operators and their associated symbols.:


Addition (+): Addition '+' operator adds two operands. It is also possible to add texts with the "+" operator. 

    
    console.log(5 + 5);                 // 10
    console.log("Team" + "DefineX");    // "Team DefimeX"

Subtraction (-): Subtraction ‘-‘ operator subtracts two operands together. 

    
    console.log(5 - 3); // 2

Multiplication (*): Multiplication ‘*’ operator multiplies two operands. 

    
    console.log(5 * 5); // 25

Division (/): Division ‘/’ operator divides two operands by dividing the numerator by the denominator. 

    
    console.log(5 / 5); // 1

Modulus (%): The modulus '%' operator returns the remainder of integer division. division.  

    
    console.log(5 / 4); // 1

Exponentiation (**): The exponentiation '**' operator transfers the raised value of the first operator to the second operator. 

    
    console.log(5 ** 3); // 125

Increment(++): Increment ‘++’ operator increases an integer value by one. 

    
    let x = 10;
    let y = x++;
    console.log(x); // 11

    let z = 10;
    let w = ++z;
    console.log(z); // 11

Decrement (--): Decrement ‘--‘ operator decreases an integer value by one. 

    
    let x = 10;
    let y = x--;
    console.log(x); // 9

    let z = 10;
    let w = --z;
    console.log(z); // 9

Assignment Operators

The assigned value is evaluated during the assignment operation. To assign a single value to several variables, the assignment operator can be chained.


Assignment (=): The left operand is given the value of the right operand with this operator. 

    
    let x = "Team DefineX"; 
    console.log(x); // Team DefineX

Addition Assignment (+=): Sums the values of the left and right operands and assigns the total to the left operand. 

    
    let x = 9;
    x += 1;
    console.log(x); // 10

    let y = "Team ";
    y+= "DefineX";
    console.log(y); // "Team DefineX"

Subtraction Assignment (-=): The right side value is subtracted from the left side value, and the outcome is then assigned to the left operand. 

    
    let x = 9;
    x -= 1;
    console.log(x); // 8

    let y = "Team ";
    y-= "DefineX";
    console.log(y); // NaN

Multiplication Assignment (*=): A variable is multiplied by the value of the right operand, and the result is then assigned to the variable. 

    
    let x = 9;
    x *= 2;
    console.log(x); // 18

Division Assignment (/=): A variable is divided by the value of the right operand, and the outcome is then assigned to the variable. 

    
    let x = 9;
    x /= 3;
    console.log(x); // 3

Modules/Remainder Assignment (%=): It divides a variable by the right operand's value and then applies the remainder to the variable. 

    
    let x = 9;
    x %= 4;
    console.log(x); // 1

Exponentiation Assignment (**=): This increases a variable's value to the power of the right operand. 

    
    let x = 5;
    x **= 3;
    console.log(x); // 125

Comparison Operators

The basic purpose of comparison operators is to carry out the logical processes that establish the equality or difference between the values.


Equality (==): It is a comparison operator that modifies operands of the same type before comparison. Thus, JavaScript turns any string into a number when comparing it to a number. An empty string is always converted to zero. A string that has no numerical value is converted to NaN (Not a Number), which results in false. 

    
    console.log(2 == "2"); // true

Strict equality (===): JavaScript's strict equality comparison operator returns false for values that do not share a common type. With this operator, type casting is done for equality. It will give a false result if we compare 2 with "2" using the comparison operator ===. 

    
    console.log(2 === "2"); // false

Inequality (!=): It evaluates the type-based equality of two operands. The condition is true if the value and type are both equal; otherwise, it is false. 

    
    console.log(2 != 2);    // false
    console.log("x" != 5);  // true

Strict inequality(!==): Inequality between two operands is compared. If the operands are not equal, the statement is true. 

    
    console.log(2 !== "2"); // true
    console.log(2 !== 5);   // true

Greater than (>): This operator determines if the value on the left is greater than the value on the right. If yes, the function returns true; if no, it returns false. 

    
    console.log(2 > 3); // false
    console.log(2 > 1); // true

Less than (<): This operator determines whether the value on the left side is less than the value on the right side. It returns true if the answer is yes; otherwise, it returns false. 

    
    console.log(2 < 3); // true
    console.log(2 < 1); // false

Greater than or Equal to (> =): This operator determines whether the operand on the left is greater than or equal to the operand on the right. If yes, then true is returned; otherwise, false is returned. 

    
    console.log(2 > 3);     // false
    console.log(2 >= 2);    // true
    console.log(2 > 1);     // true

Less than or Equal to (<= ): TThis operator determines whether the value of the left operand is less than or equal to the value of the right operand. If the answer is affirmative, it returns true; otherwise, it returns false. 

    
    console.log(2 < 3);     // true
    console.log(2 <= 2);    // true
    console.log(2 < 1);     // false

Logical Operators

These operators are used to define the logic between variables or values.


Logical AND (&&): It determines whether or not two operands are non-zero (0, false, undefined, null, or "" are considered as zero). If yes, then the final operand is returned when evaluating from left to right. 

    
    let x = true;
    let y = true;
    let z = false;
    console.log(x && y); // true
    console.log(x && z); // false

    let a = 5, b = 6;
    console.log(a && b); // 6

Logical OR (||): When evaluating from left to right, it checks whether two operands are non-zero (0, false, undefined, null, or "" is considered zero), and if so, it returns the first operand. 

    
    let x = true;
    let y = true;
    let z = false;
    console.log(x || y); // true
    console.log(x || z); // false

    let a = 5, b = 6;
    console.log(a || b); // 5

Logical NOT (!): It flips the operand's (or condition's) boolean outcome. 

    
    let x = true;
    let y = true;
    let z = false;
    console.log(!(x && y)); // false
    console.log(!(x && z)); // true

Ternary Operator

Three operands make up the ternary operator. It is the if...else operator in its simplest form.


Ternary Operator(?): It is like the short form of the if...else condition. 

    Y =  ? A : B
    If the condition is true then Y = A otherwise Y = B

    
    let x = 5;
    let y = 4;
    let z = x > y ? x : y;
    console.log(z); // 5

typeof Operator

It returns the data type of its operand as a string. Any object, function, or variable can be used as the operand.


JavaScript typeof: It gives back the operand type. Undefined, Object, boolean, number, string, symbol, and function are the provided types in JavaScript. 

    
    typeof variable;
    

    
    var x = 35;
    var y = "Team DefineX";
    var z = "";
    var w = null;

    console.log("Type of a = " + (typeof x)); // number
    console.log("Type of b = " + (typeof y)); // string
    console.log("Type of c = " + (typeof z)); // string
    console.log("Type of d = " + (typeof w)); // object
    console.log("Type of e = " + (typeof e)); // undefined
