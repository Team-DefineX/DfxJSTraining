The “if” statement

The if (...) statement runs a block of code if the result of evaluating a condition enclosed in parenthesis is true. 

    
    let bornYear = prompt('When were you born?', '');

    if (bornYear == 1988) console.log('You are right!');

A basic equality check (bornYear == 1988) is used in the example above, but the condition can be a lot more complicated.

Wrapping our code block in curly brackets is necessary if we wish to execute numerous statements: 

    
    if (bornYear == 1988) {
        console.log("That's correct!");
        console.log("Do not be sad. You ara not old :D");
    }

If you use an if statement in your code block, even if it is the only statement that needs to run, we advise you to surround it with curly braces {}. This enhances clarity.


Boolean conversion

The expression enclosed in parentheses is evaluated by the if (...) statement, which then changes the outcome to a Boolean.


Let us review the conversion rules from the chapter, Type Conversions:

  • A 0 becomes false, as do an empty string "", null, undefined, and NaN. As a result, they are referred to as "falsy" values.
  • Other values become true and are referred to as "truthy".

As a result, the code would never execute in this case: 

    
    if (0) { // 0 is falsy
         ...
    }

…and inside this condition – it always will: 

    
    if (1) { // 1 is truthy
        ...
    }

Another option is to give if a pre-evaluated boolean value, like in this example: 

    
    let cond = (bornYear == 1988); // equality evaluates to true or false

    if (cond) {
        ...
    }

The “else” clause

An else block may be included in the if statement. When the condition is falsy, it runs. 

    
    let bornYear = prompt('When were you born?', '');

    if (bornYear == 1988) {
        alert('You guessed it right!');
    } else {
        alert('oh no'); // any value except 1988
    }

Several conditions: “else if”

We might want to test multiple variations of the same condition. That's what the else if clause allows for. 

    
    let bornYear = prompt('When were you born?', '');

    if (bornYear < 1988) {
        alert('I am not so old');
    } else if (bornYear > 1988) {
        alert('I am not so young');
    } else {
        alert('Well done!');
    }

JavaScript initially verifies if the year < 1988 in the code above. If that is falsy, it proceeds to the following condition year > 1988. It displays the last alert if that is likewise falsy.


More blocks (else..if) may exist. The last else is not obligatory.


Conditional operator ‘?’

Assigning a variable based on a condition is sometimes necessary.


For instance: 

    
    let accessAllowed;
    let age = prompt('How old are you?', '');

    if (age > 18) {
        accessAllowed = true;
    } else {
        accessAllowed = false;
    }

    console.log(accessAllowed);

This can be accomplished more quickly and easily with the help of the so-called "conditional" or "question mark" operator.

The symbol for the operator is a question mark ?. Because there are three operands in the operator, it is sometimes referred to as "ternary". In reality, there is only one operator in JavaScript with that many. 

    
    let result = condition ? value1 : value2;

value1 is returned if the condition is true; if not, value2 is returned. 

    
    let accessAllowed = (age > 18) ? true : false;

In theory, the parentheses around age > 18 can be removed. Due to its low precedence, the question mark operator runs after the comparison >.


This instance will fulfill the same thing as the preceding one: 

    
    // the comparison operator "age > 18" executes first anyway
    // (no need to wrap it into parentheses)
    let accessAllowed = age > 18 ? true : false;
