The “while” loop

The syntax for the while loop is as follows: 

    
    while (condition) {
        // loop body
    }

The code from the loop body is performed while the condition is truthy.


For example, the loop below produces i while x < 5: 

    
    let x = 0;
    while (x < 5) { // 0, then 1, 2, 3, 4
        console.log(i);
        i++;
    }

Iteration refers to a single execution of the loop body. In the preceding example, the loop iterates five times.


If x++ was missing from the preceding example, the loop would (in theory) continue endlessly. In reality, the browser provides methods to stop such loops, and we may kill the process with server-side JavaScript.


The “do…while” loop

Using the do..while syntax, the condition check can be relocated below the loop body: 

    
    do {
        // loop body
    } while (condition);

The loop will first execute the body, then check the condition, and then perform it again and again until it is truthy.

For example: 

    
    let x = 0;
    do {
        alert(x);
        x++;
    } while (x < 5);

When you want the loop's body to run at least once regardless of whether the condition is truthy, you should only use this syntax. Generally, the alternative format is favored: while(...) {…}.


The “for” loop

The for loop is more complicated, but it is also the most widely used.


It appears as follows: 

    
    for (begin; condition; step) {
        // loop body
    }

Let's look at an example to discover the meaning of these parts. The following loop executes console.log(x) for x ranging from 0 to (but not including) 5: 

    
    for (let i = 0; i < 5; i++) { // 0, then 1, 2, 3, 4
        console.log(i);
    }

Breaking the loop

A loop normally ends when its condition turns falsy.


The special break directive, on the other hand, allows us to force the exit at any time.


For instance, the "break" command is executed when the user enters the true year when the loop below requests the user's birth year. 

    
    while (true) {
        let birthYear = prompt("Which year is my birth year?", '');
        if (birthYear == 1988) break;
    }

The "infinite loop + break as needed" combination is ideal for scenarios in which the condition of a loop must be verified not at the beginning or the end of the loop, but in the middle or even numerous places throughout its body.


Continue to the next iterations

A "lighter version" of break is the continue directive. The loop is not completely stopped. Rather, it compels the loop to begin a fresh iteration (assuming the condition allows).


If we want to go on to the next iteration and are finished with this one, we can use it.


The following loop outputs only odd values by using continue: 

    
    for (let x = 0; x < 10; x++) {
        // if true, skip the remaining part of the body
        if (x % 2 == 0) continue;
        console.log(x); // 1, then 3, 5, 7, 9
    }
