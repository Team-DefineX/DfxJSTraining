JavaScript can be added to your HTML file in three ways:


  • Inline JavaScript
  • Internal JavaScript
  • External JavaScript

Inline JavaScript: Here, you will find JavaScript code enclosed in HTML tags with JS-specific attributes.
HTML tags, for instance, contain event attributes that enable you to execute some codes inline when an event is triggered. 

    
    <html>
    <!DOCTYPE html>
    <body>
        <button onclick="alert('Welcome to Definex Javascript Training')">Click me!</button>
    </body>
    </html>

Internal JavaScript: By writing the code between the <script> and </script> tags, we can add JS directly to an HTML file. The <script> tag can be placed either within the <head> or <body> tags, depending on what's needed. 

    
    <!DOCTYPE html>
    <html>
    <head>
      <meta charset="UTF-8">
      <title>Definex Javascript Training</title>
    </head>
    <body>
    <!-- JavaScript Code -->
      <script>
        console.log("Welcome to Definex Javascript Training");
      </script>
    </body>
    </html>

External JavaScript: The JS code can be pasted into a file that has a .js extension. After generating the file, add it in the <script src=”file name.js”> tag so that it may be imported inside the HTML file's <head> or <body> tag. 

    
    <!DOCTYPE html>
    <html>
    <head>
        <meta charset="UTF-8">
        <title>Definex Javascript Training</title>
        <script src="main.js"></script>
    </head>
    <body>
    </body>
    </html>
    

    
    /* JavaScript code can be embedded inside head section or body section */
    console.log("Welcome to Definex Javascript Training");
    // JavaScript file name: main.js

External References

There are three possible ways to reference an external script:
  • With a full URL (a full web address)
  • With a file path (like /js/)
  • Without any path
    
    <script src="https://www.w3schools.com/js/myScript.js"></script>
    <script src="/js/myScript.js"></script>
    <script src="myScript.js"></script>
