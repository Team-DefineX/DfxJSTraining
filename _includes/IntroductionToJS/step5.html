This section discusses how to declare variables in JavaScript. The var statement in JavaScript is used to declare variables that are scoped to the closest function block.


JavaScript will automatically assign an undefined value to a variable if its value is not set at the time of declaration.


Variables cannot be used prior to the declaration; otherwise, an error will occur.


A few general guidelines for naming variables include:

  • The names of variables can never begin with a number.
  • MyName and myname are two separate variables because of the case sensitivity of variable names. Using two variables with the same name but different case is not recommended.
  • The names of variables and keywords can't be the same. Check out the MDN’s keyword documentation for a detailed list of keywords. 
    
    var variable_name = value;
Parameter
  • var: JavaScript reserved keyword.
  • var_name: Name of the variable.
  • value: Optional, Initial value assign at the time of declaration.

You can declare one or more variables in a single statement separated by a comma. 

    
    var var1 = val1, var2 = val2, ..., varN = valN;

Without the var keyword, a variable cannot be declared or initialized in ''Strict Mode JavaScript'' because the system generates an error known as ''a reference error''. 

    
    "use strict";   // strict mode specification 
    var a = "A";
    b = "B";        // give an ReferenceError

One or more variables are defined and set to their values. 

    
    var a = 0, b = 0;

Variable override: The variable's value can be reassigned. 

    
    var a = "Team";
    if (a){
        console.log("variable a: " + a);
    }

    var a ="DefineX";
    console.log("reinitializing a: " + a);

var in functional scope: In the following var statement example, the scope of the quote variable can be accessed within the scope of the callme() function. The variable cannot be accessed outside of the function: 

    
    function callme() {
        var age = 35;
        console.log("your age : " + age); // "your age : 35"
    }

    callme();
    console.log("your age : " + age);    // Uncaught ReferenceError: age is not defined"

var in global scope: Since the variable is declared outside of the function, it can be accessed both within and without the function's scope: 

    
    var age = 35;
    function callme() {
        console.log("your age : " + age); // "your age : 35"
    }

    callme();
    console.log("your age : " + age);    // "your age : 35"
