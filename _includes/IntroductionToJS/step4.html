Programming frequently involves extensive teamwork. Sometimes when we go back to our own code, even just an hour later, it might get challenging for us to comprehend! For these reasons, it's beneficial to add notes to our code for future reference or for other programmers.


JavaScript allows us to add comments to our code that the computer will disregard as our program runs. Just human readers are intended for these comments.


Comments can provide context for the code, directions for other developers working with the code, and other helpful comments.


There are two types of code comments in JavaScript:


        1. A single line comment is used to comment out a single line and can be recognized by the two forward slashes // that come before it: 

    
      // 5
      console.log(5);

A single line comment can also be used to comment on a line of code: 

    
    console.log(5);  // 5

This syntax can also be used to comment out something in the middle of a line of code: 

    
    console.log(/*IGNORED!*/ 5);  // 5

        2. A multi-line comment will comment out numerous lines and is indicated with /* to start the comment and */ to end the comment. 

    
    /*
    This is all commented 
    console.log(10);
    None of this is going to run!
    console.log(99);
     */
