This section mentions how to declare JavaScript constants.
A constant variable with a value is declared using the const statement in JavaScript. By the way, the keyword const, which stands for constant, was introduced in ES6.


If you're not sure whether to use the let or const keyword, think about whether you'll need to change the value of the variable later. If you need to change the variable's value, use let. If not, use const. 

    
    const constant_name = value;
Parameter
  • const: JavaScript reserved keyword.
  • constant_name: Name of the constant variable.
  • value: Required, Initializing constant value.

You can declare one or more constants in single statement separated by a comma. 

    
    const con1 = val1, con2 = val2, ..., conN = valN;

Constant variables must be assigned a value when declared. If you try to declare a const variable without a value, you’ll get a SyntaxError.
Constant variables must be initialized with a value. You will receive a SyntaxError if you attempt to declare a constant variable without a value. 

    
    const a = 10;
    console.log("Constant a: ", a);     // Constant a: 10
    
    
    
    const b;                            // weird, const can define without initial value
                                        // Error: Uncaught SyntaxError: Missing initializer in const declaration"
    console.log("Constant b: ", b);     // automatic assign 'undefined'

Const variables cannot be reassigned because they are constant. Attempting to reassign a const variable will result in a TypeError. 

    
    const a = 10;
    a = 20;     // TypeError: Assignment to constant variable.
    
    
    
    const a = 10;
    var a = 20;     // Error: Identifier 'a' has already been declared"
Example
    
    const c = 20;                    // Define and initializing 'c' constant variable
    const d = c;                     // Define 'd' constant variable, initialize constant 'c'
    console.log("Constant c: ", c);  // Constant c: 20
    console.log("Constant d: ", d);  // Constant d: 20
Example
    
    const obj = {"a": "A", "b": "B"};       // Define and initializing constant object
    console.log("Constant Object:", obj);   // { a: "A", b: "B" }
    console.log("Constant obj.a:", obj.a);  // Constant obj.a: "A"
Example
    
    const obj = {"a": "A", "b": "B"};       // Define and initializing constant object
    obj.a = "AA";                           // 'a' key, try to reassign
    console.log("Constant obj.a:", obj.a);  // Constant obj.a: "AA"
