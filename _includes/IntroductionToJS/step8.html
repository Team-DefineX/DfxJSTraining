Data types are the classifications we give to the different kinds of data that we use in programming. In JavaScript, there are seven fundamental data types:


Number: Any number, including numbers with decimals: 4, 8, 1516, 23.42. 

    
    // With decimals:
    let x = 56.00;
        
    // Without decimals:
    let y = 56;

Exponential Notation

Extra large or extra small numbers can be written with scientific (exponential) notation: 

    
    let z = 123e5;    // 12300000
    
    let w = 123e-5;   // 0.00123

String: Any grouping of characters on your keyboard (letters, numbers, spaces, symbols, etc.) surrounded by single quotes: ' ... ' or double quotes " ... ", though we prefer single quotes. Some people like to think of string as a fancy word for text. 

    
    // Using double quotes:
    let string1 = "Team DefineX";
    
    // Using single quotes:
    let string2 = 'Team DefineX';

Boolean: This data type only has two possible values— either true or false (without quotes). It’s helpful to think of booleans as on and off switches or as the answers to a “yes” or “no” question. 

    
    Boolean b = new Boolean(value);  
    
    document.write(10<20); //true  
    document.write(10<5); //false  

    let x = 5;
    let y = 5;
    let z = 6;
    (x == y)       // true
    (x == z)       // false

BigInt: All JavaScript numbers are stored in a a 64-bit floating-point format. JavaScript BigInt is a new datatype (ES2020) that can be used to store integer values that are too big to be represented by a normal JavaScript Number. 

    
    let x = BigInt("123456789012345678901234567890");

Null: This data type represents the intentional absence of a value, and is represented by the keyword null (without quotes). 

    
    let num = null;
    console.log(num);           // null
    console.log(typeof num);    // "object"

Undefined: This data type is denoted by the keyword undefined (without quotes). It also represents the absence of a value though it has a different use than null. undefined means that a given value does not exist. 

    
    let num;            // Value is undefined, type is undefined
Any variable can be emptied, by setting the value to undefined. The type will also be undefined. 
    
    num = undefined;    // Value is undefined, type is undefined

Symbol: A newer feature to the language, symbols are unique identifiers, useful in more complex coding. No need to worry about these for now. 

    
    const mySymbol = Symbol();

    const mySymbol = Symbol("my description");

    const sym1 = Symbol("foo");
    const sym2 = Symbol("foo");

    console.log(sym1 === sym2); // false

Object: JavaScript objects are written with curly braces {}. Object properties are written as name:value pairs, separated by commas. 

    
    const person = {firstName:"Gökhan", lastName:"Ertaş", age:34, eyeColor:"brown"};

Array: JavaScript arrays are written with square brackets []. Array items are separated by commas. 

    
    const dfxCoreValues = ["Driven By Impact", "Best Enviroment for Best People", "Future in Mind", "Define Next"];

Date: The JavaScript date object can be used to get year, month and day. You can display a timer on the webpage by the help of JavaScript date object. You can use different Date constructors to create date object. It provides methods to get and set day, month, year, hour, minute and seconds.

Constructor

You can use 4 variant of Date constructor to create date object.

  1. Date()
  2. Date(milliseconds)
  3. Date(dateString)
  4. Date(year, month, day, hours, minutes, seconds, milliseconds)

    
    var today=new Date();  
    document.getElementById('txt').innerHTML=today; // Wed May 17 2023 09:55:58 GMT+0300 (GMT+03:00)

    var date=new Date();  
    var day=date.getDate();  
    var month=date.getMonth()+1;  
    var year=date.getFullYear();  
    document.write(day+"/"+month+"/"+year);         // 17/5/2023

    var today=new Date();  
    var h=today.getHours();  
    var m=today.getMinutes();  
    var s=today.getSeconds();  
    document.getElementById('txt').innerHTML=h+":"+m+":"+s;  // 9:55:58

    const date = new Date("2022-03-25");
    ocument.write(date);                            // Fri Mar 25 2022 03:00:00 GMT+0300 (GMT+03:00)
