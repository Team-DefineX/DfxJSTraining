Data types are the classifications we assign to the various data forms utilized in programming. There are eight main data types in JavaScript:


Any number, including decimal numbers: 4, 8, 1516, 23.42. 

    
    // With decimals:
    let x = 56.00;
        
    // Without decimals:
    let y = 56;

Exponential Notation

Scientific (exponential) notation is a way to express extremely big or extremely small numbers: 

    
    let z = 123e5;    // 12300000
    
    let w = 123e-5;   // 0.00123

String: Any group of characters on your keyboard (letters, numerals, spaces, symbols, etc.) that are enclosed in single quotes: '...' or double quotes: "... ". (although single quotes are preferred). Some people consider string to be a sophisticated term for text. 

    
    // Using double quotes:
    let string1 = "Team DefineX";
    
    // Using single quotes:
    let string2 = 'Team DefineX';

Boolean: This data type can only take the values true (without the quotes) or false (without the quotes). The best way to understand Booleans is to think of them as "on" and "off" switches or as the answers to ‘’yes/no’’ questions. 

    
    Boolean b = new Boolean(value);  
    
    document.write(10<20); //true  
    document.write(10<5); //false  

    let x = 5;
    let y = 5;
    let z = 6;
    (x == y)       // true
    (x == z)       // false

BigInt: In a 64-bit floating-point format, all JavaScript numbers are kept. When an integer value is too large to be represented by a standard JavaScript Number, JavaScript BigInt, a new datatype (ES2020), can be used to store it. 

    
    let x = BigInt("123456789012345678901234567890");

Null: The keyword null (without quotes) denotes this data type, which represents the intentional lack of a value. 

    
    let num = null;
    console.log(num);           // null
    console.log(typeof num);    // "object"

Undefined: The word undefined (without quotes) designates this data type. Although it has a different purpose than null, it also signifies the lack of a value. Undefined denotes the absence of a certain value. 

    
    let num;            // Value is undefined, type is undefined
By setting the value to undefined, you can empty any variable. In addition, the type will be undefined: 
    
    num = undefined;    // Value is undefined, type is undefined

Symbol: a relatively recent addition to the language, are distinctive identifiers helpful in more complicated coding. These don't need to be a concern right now. 

    
    const mySymbol = Symbol();

    const mySymbol = Symbol("my description");

    const sym1 = Symbol("foo");
    const sym2 = Symbol("foo");

    console.log(sym1 === sym2); // false

Object: Curly braces {} are used to write JavaScript objects. Name:value pairs, separated by commas, are used to represent object properties. 

    
    const person = {firstName:"Gökhan", lastName:"Ertaş", age:34, eyeColor:"brown"};

Array: In JavaScript, arrays are enclosed in square brackets []. Commas are used to distinguish the array elements. 

    
    const dfxCoreValues = ["Driven By Impact", "Best Enviroment for Best People", "Future in Mind", "Define Next"];

Date: The year, month, and day can be obtained using the JavaScript date object. With the aid of a JavaScript date object, you can display a timer on a webpage. When creating a date object, you can choose from a variety of date constructors. It offers ways to obtain and set days, months, years, hours, minutes, and seconds.

Constructor

There are four variants of the date constructor that can be used to produce a date object.

  1. Date()
  2. Date(milliseconds)
  3. Date(dateString)
  4. Date(year, month, day, hours, minutes, seconds, milliseconds)

    
    var today=new Date();  
    document.getElementById('txt').innerHTML=today; // Wed May 17 2023 09:55:58 GMT+0300 (GMT+03:00)

    var date=new Date();  
    var day=date.getDate();  
    var month=date.getMonth()+1;  
    var year=date.getFullYear();  
    document.write(day+"/"+month+"/"+year);         // 17/5/2023

    var today=new Date();  
    var h=today.getHours();  
    var m=today.getMinutes();  
    var s=today.getSeconds();  
    document.getElementById('txt').innerHTML=h+":"+m+":"+s;  // 9:55:58

    const date = new Date("2022-03-25");
    ocument.write(date);                            // Fri Mar 25 2022 03:00:00 GMT+0300 (GMT+03:00)
