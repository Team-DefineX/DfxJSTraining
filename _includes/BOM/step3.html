'Location' Object

As part of the BOM, the location object represents the URL of the browser and is used to change the URL of the browser window or navigate in the browser. You can access the location object by referencing the location property of the window or document object.

JavaScript Location properties:
Location.href

The location object's href property is an attribute that represents the URL of the current page in the browser. This property contains the full URL displayed in the browser's address bar, allowing you to manipulate the page's URL and navigate the page.

Example of the location.href property: 

    
location.href = "http://localhost:3000/api/products?type=phones&page=2";
console.log(location.href);
Location.protocol

This property allows you to determine and access the protocol used by the page. It is particularly important for security and browser settings.

You can use the location.protocol property to check which protocol the page is using: 

    
let pageProtocol = location.protocol;
console.log("Page Protocol: " + pageProtocol);
Location.host

This property allows you to determine which server hosts the page and the port that is being used.

location.host property to obtain the hostname and port of the page: 

    
let pageHost = location.host;
console.log("Page Hostname and Port: " + pageHost);
Location.port

The location.port represents the port number of the URL. 

    
let port = location.port;
console.log("Port: " + port);
Location.pathname

This property contains the file path and file name in the page's URL. For example, if the current page URL is "https://www.example.com/products/shoes.html" location.pathname will contain the string "/products/shoes.html"

Example of location.pathname: 

    
let pagePathname = location.pathname;
console.log("Page Pathname: " + pagePathname);
Location.search

The query string contains a list of parameters after the "?" character in the URL and is typically used to transmit data or specify queries.

If the current page URL is like this: "https://www.example.com/products?category=shoes&color=blue" location.search will contain the string "?category=shoes&color=blue"

Example of location.search: 

    
let queryString = location.search;
console.log("Query String: " + queryString);
Location.hash

An anchor, or hash, is the portion of the URL that comes after the "#" character and is typically used to reference a particular section or location within a page. Anchors are commonly used to provide direct links to specific sections or positions within web pages.

If the current page URL is like this: "https://www.example.com/page#section1" location.hash will contain the string "#section1" For example, it can be used to scroll to a specific section within a page when a particular anchor is clicked or to implement custom actions related to the anchor.

Example usage: 

    
let anchor = location.hash;
console.log("Anchor: " + anchor);
Location.origin

The page origin includes the protocol, hostname, and port number of a URL. This identifies where the page is hosted and through which port it can be accessed. 

    
let pageOrigin = location.origin;
console.log("Page Origin: " + pageOrigin);
Manipulating the location:
assign()

location.assign() is a method used in JavaScript to redirect the current page's URL in the browser to another URL. This method not only redirects the browser window to a specific URL but also adds a new entry to the browser's navigation history. This allows users to go back to the previous page using the browser's "Back" button. 

    
location.assign("https://www.example.com/new-page");

Additionally, the following code accomplishes the same task: 

    
window.location.href = "https://www.example.com/new-page";
replace()

location.replace() is a method used in JavaScript to change the URL of the current page in the browser to a different URL. Similar to the location.assign() method, it redirects the page to a specific URL; however, when location.replace() is used, it does not add a new entry to the browser's navigation history. This means that users cannot go back to the previous page using the browser's "Back" button. 

    
location.replace("https://www.example.com/new-page");
reload()

location.reload() is a method used in JavaScript to reload the current page in the browser. This method is used to refresh the content and resources of the current page. After the page is reloaded, all content and scripts are reinitialized. 

    
location.reload();
URLSearchParams

URLSearchParams is a class in the JavaScript language and is used to handle querying URLs in web browsers. The URLSearchParams is used to extract query parameters from a URL, add or modify query parameters, and is also a useful tool to convert query parameters to a string or extract query parameters from a string. 

    
const urlParams = new URLSearchParams(location.search);
for (const [key, value] of urlParams) {
    console.log(`${key}:${value}`);
}
Redirect to a new URL

You can change the URL using the location object in JavaScript. To completely change the URL, you can use either location.href or the location.assign() method. Examples of how to use both methods:

Changing the URL using location.href: 

    
location.href = "https://www.example.com/newpage.html";

Changing the URL using the location.assign() or location.replace() methods: 

    
location.assign("https://www.example.com/newpage.html");
location.replace("https://www.example.com/newpage.html");

Remember: To redirect to a new URL without creating a new entry in the history stack of the browser, you use the replace() method of the location object.
