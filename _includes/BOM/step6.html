History Object

When you launch the web browser and open a new webpage, the web browser creates a new entry in its history stack. If you navigate to another webpage, the web browser also creates a new entry in the history stack. The history stack stores the current page and previous pages that you visited. history object allows you to access the browsing history, navigate between pages, and move forward or backward in the navigation history.

The history object has the following commonly used properties and methods:

1- history.length: This property returns the number of page transitions in the browser's navigation history.

2- history.back: This method lets you navigate back in the browser's history, effectively returning to the previous page.

3- history.forward: This method allows you to navigate forward in the browser's history, moving to the next page.

4- history.go: This method enables you to navigate a specified number of steps forward or backward in the browser's navigation history. You can use a positive integer to move forward and a negative integer to move backward by a certain number of pages.

Example of usage: 

    
// Accessing the browser history
var historyLength = history.length;

// Navigating back in the browser's history
history.back();

// Navigating forward in the browser's history
history.forward();

// Navigating a specific number of steps in the history
history.go(2);

To refresh the current page, you either pass 0 or no argument to the go() method: 

    
history.go(0);
history.go();

Task

Let there be two pages named page1.html and page2.html. Let there be a "reload" and "next" button in page1.html. When you press the "Next" button, it will go to page2.html. Let there be "prev" and "reload" buttons on page2. When you press the "prev" button, it will go to "page1". Let the "reload" button refresh the page.


page1.html
          
<!DOCTYPE html>
<html lang="en">
<head>
  <title>Page 1</title>
</head>
<body>
  <h1>PAGE - 1</h1>
  <button onclick="reload()">Reload</button>
  <button onclick="next()">Next</button>

  <script>
    function reload () {
      history.go();
    }
    function next () {
      location.href = new URL("page2.html", window.location.href);
    }
  </script>
</body>
</html>

<!DOCTYPE html>
<html lang="en">
<head>
  <title>Page 2</title>
</head>
<body>
  <h1>PAGE - 2</h1>
  <button> onclick="prev()">Prev</button>
  <button> onclick="reload()">Reload</button>
  
  <script>>
    function reload () {
      history.go();
    }
    function prev () {
      history.back()
    }
  </script>
</body>
</html>
