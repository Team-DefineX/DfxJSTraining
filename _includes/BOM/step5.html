'Screen' Object

screen object provides the attributes of the screen on which the current window is being rendered. The screen object has properties and methods that allow you to access the browser's screen properties. screen object is typically used by the web analytic software like Google Analytics to collect information of the client device on which the web browsers are running.

The properties of the screen object and where they are commonly used:

1- screen.width and screen.height: Provide information about the width and height of the browser's screen in pixels. 

    
console.log("width: " + screen.width);
console.log("height: " + screen.height);

2- screen.availWidth and screen.availHeight: Offer details about the available screen area's width and height in pixels. This does not take into account areas outside the screen, such as browser toolbars. 

    
console.log("availWidth: " + screen.availWidth);
console.log("availHeight: " + screen.availHeight);

2- screen.colorDepth and screen.pixelDepth: Provide information about the color depth and pixel depth of the screen. This determines the color quality of the screen. 

    
console.log("colorDepth: " + screen.colorDepth);
console.log("pixelDepth: " + screen.pixelDepth);
Other properties of screen object
Property Description
left Represents the pixel distance of the current screen’s left side.
top Represents the pixel distance of the current screen’s top.
availTop A read-only property that returns the first pixel from the top that is not taken up by system elements.
orientation Returns the screen orientation as specified in the Screen Orientation API.
