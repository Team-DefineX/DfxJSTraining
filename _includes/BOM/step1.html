Classes for JavaScript

Classes are a fundamental part of the language introduced in ECMAScript 6 (ES6) to provide a more structured and object-oriented approach to organizing and defining objects. They allow you to create reusable templates for objects with shared properties and methods. Here are three key details about JavaScript classes:

Let's create a HeroProfile class step-by-step, explaining each part along the way. We'll build upon it to demonstrate class inheritance later.

First, we'll declare the HeroProfile class and define its constructor. The constructor is a special method that gets called automatically when we create a new instance of the class using the new keyword. It allows us to initialize the properties of the hero. 

            
                class HeroProfile {
                    constructor(name, age, power) {
                      this.name = name;
                      this.age = age;
                      this.power = power;
                    }
                  }

In this step, we've defined the HeroProfile class with a constructor that takes three parameters: name, age, and power. The constructor sets these values as properties of the object being created.

Next, let's add some methods to the HeroProfile class to perform actions related to the hero. 
            
                class HeroProfile {
                    constructor(name, age, power) {
                      this.name = name;
                      this.age = age;
                      this.power = power;
                    }
                  
                    // Method to introduce the hero.
                    introduce() {
                      console.log(`Hi, I'm ${this.name}, and I'm a superhero!`);
                    }
                  
                    // Method to display the hero's age.
                    displayAge() {
                      console.log(`${this.name} is ${this.age} years old.`);
                    }
                  
                    // Method to use the hero's power.
                    usePower() {
                      console.log(`${this.name} uses ${this.power}!`);
                    }
                  }
In this step, we've added three methods to the HeroProfile class: introduce(), displayAge(), and usePower(). These methods allow us to introduce the hero, display their age, and use their power, respectively.

Now that we have defined the HeroProfile class, we can create an instance of it by using the new keyword and passing the necessary parameters to the constructor. 
            
                // Creating an instance of the HeroProfile class.
                const ironMan = new HeroProfile('Iron Man', 40, 'Repulsor Rays');
                
                // Using the methods on the instance.
                ironMan.introduce(); // Output: "Hi, I'm Iron Man, and I'm a superhero!"
                ironMan.displayAge(); // Output: "Iron Man is 40 years old."
                ironMan.usePower(); // Output: "Iron Man uses Repulsor Rays!"
In this step, we've created an instance of the HeroProfile class named ironMan with the provided parameters. We then used the methods introduce(), displayAge(), and usePower() on the ironMan object to introduce the hero, display their age, and use their power, respectively.

Now, let's demonstrate class inheritance by creating a subclass called SuperVillainProfile that inherits from the HeroProfile class. The SuperVillainProfile class will have additional properties and methods specific to villains. 
            
                class SuperVillainProfile extends HeroProfile {
                    constructor(name, age, power, evilPlan) {
                      // Call the constructor of the parent class using super().
                      super(name, age, power);
                      this.evilPlan = evilPlan;
                    }
                  
                    // Override the usePower() method from the parent class.
                    usePower() {
                      console.log(`${this.name} uses ${this.power} to execute their evil plan: ${this.evilPlan}`);
                    }
                  
                    // New method specific to SuperVillainProfile class.
                    revealEvilPlan() {
                      console.log(`${this.name}'s evil plan is to ${this.evilPlan}`);
                    }
                  }
In this step, we've defined the SuperVillainProfile class that extends the HeroProfile class using the extends keyword. It has an additional property evilPlan, and the usePower() method is overridden to include the evil plan. We've also added a new method revealEvilPlan() specific to villains.

Finally, let's create an instance of the SuperVillainProfile class and see how it inherits properties and methods from the parent class while having its own unique features. 
            
                // Creating an instance of the SuperVillainProfile class.
                const joker = new SuperVillainProfile('Joker', 35, 'Chaos', 'create anarchy in Gotham City');
                
                // Using methods on the instance.
                joker.introduce(); // Output: "Hi, I'm Joker, and I'm a superhero!"
                joker.displayAge(); // Output: "Joker is 35 years old."
                joker.usePower(); // Output: "Joker uses Chaos to execute their evil plan: create anarchy in Gotham City"
                joker.revealEvilPlan(); // Output: "Joker's evil plan is to create anarchy in Gotham City"

In this step, we've created an instance of the SuperVillainProfile class named joker. Despite being a subclass, it inherits the introduce() and displayAge() methods from the HeroProfile class. However, the usePower() method is overridden to include the evil plan. Additionally, joker has access to the revealEvilPlan() method, which is specific to the SuperVillainProfile class.

With these steps, we've demonstrated how to create and use JavaScript classes, along with class inheritance to create subclasses with specialized properties and methods.
