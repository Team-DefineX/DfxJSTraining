The "window" object is a JavaScript object that represents the browser window. This object provides access to various properties, methods, and other information about the browser window. The "window" object is the primary point of interaction with the browser window when developing web applications, and it is commonly used to control the behavior of the browser window using JavaScript.

The window.innerWidth and window.innerHeight properties provide information about the width and height of the content area of the browser window. Here's a simple example using these properties: 

            
console.log("Browser window's content width: " + window.innerWidth + " pixels");
console.log("Browser window's content height: " + window.innerHeight + " pixels");

This code prints the content width and height of the browser window to the browser console. These properties represent the size of the displayed content on the web page and do not take into account interface elements like browser bars, toolbars, and so on.

For example, you can use the following sample code to dynamically track the browser window size and recalculate it when the window size changes: 

            
function handleWindowSizeChange() {
  console.log("Browser window's content width: " + window.innerWidth + " pixels");
  console.log("Browser window's content height: " + window.innerHeight + " pixels");
}

// Call this function as the window size changes
window.addEventListener("resize", handleWindowSizeChange);

// Show the window size on initial load
handleWindowSizeChange();

The window.outerWidth and window.outerHeight properties provide information about the total width and height of the browser window, including all interface elements such as browser bars, toolbars, and other user interface components. Here is a simple example using these properties: 

            
console.log("Total width of the browser window: " + window.outerWidth + " pixels");
console.log("Total height of the browser window: " + window.outerHeight + " pixels");

This code prints the total width and height of the browser window to the browser console.

For example, you can use the following code to dynamically track the window's size and recalculate it when the window size changes: 

            
function handleWindowDimensions() {
  console.log("Total width of the browser window: " + window.outerWidth + " pixels");
  console.log("Total height of the browser window: " + window.outerHeight + " pixels");
}

// Call this function as the browser window size changes
window.addEventListener("resize", handleWindowDimensions);

// Show the window size on initial load
handleWindowDimensions();

The window.screenX and window.screenY properties provide the position of the browser window on the screen. These properties represent the horizontal (X) and vertical (Y) coordinates of the top-left corner of the browser window on the screen. Here's a simple example using these properties: 

            
console.log("Browser window's X coordinate on the screen: " + window.screenX + " pixels");
console.log("Browser window's Y coordinate on the screen: " + window.screenY + " pixels");

This code will print the X and Y coordinates of the browser window on the screen to the browser console.

For example, you can use the following code to track the window position and update these coordinates as you drag the window: 

            
function trackWindowPosition() {
  console.log("Browser window's X coordinate on the screen: " + window.screenX + " pixels");
  console.log("Browser window's Y coordinate on the screen: " + window.screenY + " pixels");
}

// Call this function as you drag the browser window
window.addEventListener("move", trackWindowPosition);

// Show the initial window position on load
trackWindowPosition();

console.log("Vertical scroll amount of the page: " + window.pageYOffset + " pixels");

The window.location property represents the URL of a page and allows you to perform actions related to the page's URL, such as redirecting to a different URL, retrieving the current URL, or detecting changes in the URL. Here are some basic examples of using the window.location property:

Page Redirection (Changing the URL):

This example uses the window.location property to redirect the browser to a different URL. 

            
// Perform a page redirection to a new URL
window.location.href = "https://www.example.com";

Retrieving the Current URL:

This example retrieves the current page's URL using the window.location property and logs it to the console. 

            
// Get the current URL of the page
console.log("Current URL: " + window.location.href);

Detecting URL Changes (When the Page Loads):

This example is used to detect changes in the page's URL. For instance, it can be used to detect when a user navigates to a different page or when there is navigation within the same page. 

            
window.addEventListener("popstate", function(event) {
  console.log("URL changed: " + window.location.href);
});

The code above interacts with the browser's navigation history to track changes in the page's URL.

Working with URL Parameters:

The window.location property allows you to work with URL parameters. For example, to retrieve parameters from the URL: 

            
// Retrieve parameters from the URL
const searchParams = new URLSearchParams(window.location.search);
const paramValue = searchParams.get("paramName");

Or to add new parameters to the URL: 

            
// Add a new parameter
const newURL = new URL(window.location.href);
newURL.searchParams.set("newParam", "value");
window.location.href = newURL.href;

These examples demonstrate different ways to interact with the page's URL using the window.location property. This property is useful for various operations related to browser navigation and URL management.

The window.name property can be used to assign a name to a browser window and communicate between windows. Here's a simple example using the window.name property: 

            
// Assign a name to the main window
window.name = "MainWindow";

// Open a new window and assign a name to it
const newWindow = window.open("", "NewWindow");
newWindow.name = "NewWindow";

// Display window names
console.log("Main Window Name: " + window.name);
console.log("New Window Name: " + newWindow.name);

This code uses the window.name property to assign names to two windows and prints these names to the console. Window names are useful for communicating between windows, especially when you want to send data or control one window from another.

The window.opener property represents the object of the parent window from which a pop-up window was opened. This property can be used by the pop-up window to communicate with the parent window. Here's a simple example of using the window.opener property:

First, let's create an HTML page representing the parent window:


parent_window.html

            
<!DOCTYPE html>
<html>
<head>
    <title>Parent Window</title>
</head>
<body>
    <button onclick="openPopup()">Open Popup</button>
    <script>
        function openPopup() {
            const popup = window.open("popup.html", "PopupWindow", "width=400, height=300");
        }
    </script>
</body>
</html>

Now, let's create an HTML page representing the pop-up window:


popup.html

            
<!DOCTYPE html>
<html>
<head>
    <title>Pop-up Window</title>
</head>
<body>
  <h1>Pop-up Window</h1>
  <button onclick="sendMessageToOpener()">Send Message to Parent Window</button>
    <script>
        function sendMessageToOpener() {
            // Access the parent window using window.opener
            if (window.opener) {
                window.opener.alert("Message from the pop-up window: Hello, Parent Window!");
            } else {
                alert("Parent Window not found.");
            }
        }
    </script>
</body>
</html>

In this code example, we've created a "Parent Window" HTML page and a "Pop-up Window" HTML page. When you click a button in the parent window, it opens a pop-up window, and this pop-up window uses window.opener to send a notification to the parent window. You can access and send notifications to the parent window using window.opener.
