Filtering Arrays
These examples demonstrate how array filtering can be used with the heroProfiles array to extract specific elements based on certain conditions.

Example Array of Heroes

  let heroProfiles = [
          {
            name: "Superman",
            secretIdentity: "Clark Kent",
            powers: ["Flight", "Super Strength"],
            age: 35,
            isHero: true
          },
          {
            name: "Batman",
            secretIdentity: "Bruce Wayne",
            powers: ["Intelligence", "Combat Skills"],
            age: 40,
            isHero: true
          },
          {
            name: "Wonder Woman",
            secretIdentity: "Diana Prince",
            powers: ["Superhuman Strength", "Lasso of Truth"],
            age: 500,
            isHero: true
          }
  ];
Example 1: Filtering heroes with powers

Let's say we want to filter out the heroes from the heroProfiles array who possess the power of flight.
We can use the filter() method to accomplish this: 


  let heroesWithFlight = heroProfiles.filter(hero => hero.powers.includes("Flight"));
  console.log(heroesWithFlight);
  // Output:
  // [
  //   {
  //     name: "Superman",
  //     secretIdentity: "Clark Kent",
  //     powers: ["Flight", "Super Strength"],
  //     age: 35,
  //     isHero: true
  //   }
  // ]
Example 2: Filtering heroes based on age

Let's consider filtering out heroes from the heroProfiles array who are older than 40 years. We can modify the filtering condition in the filter() method for this purpose: 


  let heroesOlderThan40 = heroProfiles.filter(hero => hero.age > 40);
  console.log(heroesOlderThan40);
  // Output:
  // [
  //   {
  //     name: "Wonder Woman",
  //     secretIdentity: "Diana Prince",
  //     powers: ["Superhuman Strength", "Lasso of Truth"],
  //     age: 500,
  //     isHero: true
  //   }
  // ]
Example 3: Filtering heroes with a specific secret identity

Let's filter out the heroes from the heroProfiles array who have the secret identity "Bruce Wayne". We can achieve this by using the filter() method: 


  let heroesWithSecretIdentity = heroProfiles.filter(hero => hero.secretIdentity === "Bruce Wayne");
  console.log(heroesWithSecretIdentity);
  // Output:
  // [
  //   {
  //     name: "Batman",
  //     secretIdentity: "Bruce Wayne",
  //     powers: ["Intelligence", "Combat Skills"],
  //     age: 40,
  //     isHero: true
  //   }
  // ]
Example 4: Filtering heroes with multiple powers

Let's filter out the heroes from the heroProfiles array who possess both "Flight" and "Super Strength" powers. We can use the filter() method with a combination of the every() method: 


  let heroesWithPowers = heroProfiles.filter(hero => hero.powers.every(power => ["Flight", "Super Strength"].includes(power)));
  console.log(heroesWithPowers);
  // Output:
  // [
  //   {
  //     name: "Superman",
  //     secretIdentity: "Clark Kent",
  //     powers: ["Flight", "Super Strength"],
  //     age: 35,
  //     isHero: true
  //   }
  // ]
Example 5: Filtering heroes based on a custom condition

Let's filter out the heroes from the heroProfiles array who are older than 30 and have the power "Superhuman Strength". We can use the filter() method with a custom condition: 


  let filteredHeroes = heroProfiles.filter(hero => hero.age > 30 && hero.powers.includes("Superhuman Strength"));
  console.log(filteredHeroes);
  // Output:
  // [
  //   {
  //     name: "Wonder Woman",
  //     secretIdentity: "Diana Prince",
  //     powers: ["Superhuman Strength", "Lasso of Truth"],
  //     age: 500,
  //     isHero: true
  //   }
  // ]

In this example, the filter() method is used to create a new array filteredHeroes containing the heroes who are older than 30 and possess the power "Superhuman Strength". These examples illustrate the flexibility of array filtering in JavaScript. By utilizing the filter() method and applying custom conditions, you can extract specific elements from an array based on various criteria, allowing for more targeted data manipulation and analysis.
