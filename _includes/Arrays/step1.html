Arrays Information for Javascript

An array is a special variable, which can hold more than one value. In JavaScript, an array is a data structure that allows you to store and manipulate a collection of values of any type. It is a fundamental concept in programming and is extensively used in JavaScript and many other programming languages.

Here are some common use cases and operations involving arrays in JavaScript


#1 Storing a collection of values

There are few ways of creating arrays.

"numbers" Array

let numbers = [1, 2, 3, 4, 5];
  • This is a simple array that contains a collection of numerical values.
  • It's an array of integers, specifically, with elements ranging from 1 to 5.
  • Arrays are an ordered collection of elements, and in this case, the elements are integers.
"string" Array

let teams = ["Team A", "Team B", "Team C"];
  • This array stores a collection of strings, representing different teams.
  • The elements are strings with the names of the teams, such as "Team A," "Team B," and "Team C."
"mixedArray" Array

let mixedArray = [1, "two", { name: "John", age: 32 }];
  • mixedArray is a more complex array containing a mix of different data types.
  • It includes an integer (1), a string ("two"), and an object with properties (name: "John", age: 32).
  • This demonstrates that JavaScript arrays can hold a variety of data types.
"heroProfiles" Array of Objects

let heroProfiles = [
  {
    name: "Superman",
    secretIdentity: "Clark Kent",
    powers: ["Flight", "Super Strength"],
    age: 35,
    isHero: true
  },
  {
    name: "Batman",
    secretIdentity: "Bruce Wayne",
    powers: ["Intelligence", "Combat Skills"],
    age: 40,
    isHero: true
  },
  {
    name: "Wonder Woman",
    secretIdentity: "Diana Prince",
    powers: ["Superhuman Strength", "Lasso of Truth"],
    age: 500,
    isHero: true
  }
];
  • heroProfiles is an array of objects, each representing a superhero's profile.
  • Each object has properties like "name," "secretIdentity," "powers," "age," and "isHero," along with their respective values.
  • This structure is a way to organize and store data about superheroes in a structured and readable format.

In summary, these arrays are used to store collections of values or objects, making it easier to work with and manipulate the data in JavaScript. They serve various purposes, from holding simple numbers and strings to organizing complex data, such as superhero profiles.


#2 Accessing array elements

There are few ways of accessing to arrays. 


let numbers = [1, 2, 3, 4, 5];
console.log(numbers[0]);  // Output: 1
console.log(numbers[2]);  // Output: 
console.log(heroProfiles[0].name);           // Output: "Superman"
console.log(heroProfiles[1].secretIdentity); // Output: "Bruce Wayne"
console.log(heroProfiles[1]["secretIdentity"]); //  Output: "Bruce Wayne"  Square bracket notation
console.log(heroProfiles[2].powers);         // Output: ["Superhuman Strength", "Lasso of Truth"]
console.log(numbers[0]);
  • This line accesses the first element of the numbers array.
  • Arrays in JavaScript are zero-indexed, which means the first element is at index 0.
  • Output: 1 - It will print the value 1 to the console.
console.log(numbers[2]);
  • This line accesses the third element of the numbers array.
  • Again, it's using zero-based indexing.
  • Output: 3 - It will print the value 3 to the console.
console.log(heroProfiles[0].name);
  • Here, it accesses the name property of the first object in the heroProfiles array.
  • heroProfiles[0] refers to the first object, and .name accesses the "name" property within that object.
  • Output: "Superman" - It prints the name of the first superhero, which is "Superman."
console.log(heroProfiles[1].secretIdentity);
  • This line accesses the secretIdentity property of the second object in the heroProfiles array.
  • heroProfiles[1] refers to the second object, and .secretIdentity accesses the "secretIdentity" property within that object.
  • Output: "Bruce Wayne" - It prints the secret identity of the second superhero, which is "Bruce Wayne."
console.log(heroProfiles[1]["secretIdentity"]);
  • This is another way to access the secretIdentity property of the second object using square bracket notation.
  • The square brackets allow you to access object properties with spaces or special characters.
  • Output: "Bruce Wayne" - It's the same result as the previous line, printing the secret identity.
console.log(heroProfiles[2].powers);
  • Here, it accesses the powers property of the third object in the heroProfiles array.
  • heroProfiles[2] refers to the third object, and .powers accesses the "powers" property within that object.
  • Output: ["Superhuman Strength", "Lasso of Truth"] - It prints an array of the powers possessed by the third superhero, which includes "Superhuman Strength" and "Lasso of Truth."

In summary, you access array elements using square brackets, specifying the index of the element you want to access. When working with arrays of objects, you can also use dot notation or square bracket notation to access specific properties within those objects.


#3 Modifying Array Elements and Adding Properties

Below code we demonstrate how to add new properties and access to them. 


heroProfiles[0].powers.push("Heat Vision");      // Add a power to Superman
heroProfiles[1].isRich = true;                   // Add a new property to Batm
console.log(heroProfiles[0].powers);         // Output: ["Flight", "Super Strength", "Heat Vision"]
console.log(heroProfiles[1].isRich);         // Output: true
heroProfiles[0].powers.push("Heat Vision");
  • This line modifies the first superhero's (Superman) powers.
  • heroProfiles[0] refers to the first object in the heroProfiles array, which is Superman.
  • .powers accesses the "powers" property (which is an array), and .push() adds a new element, "Heat Vision," to that array.
  • After this line, "Heat Vision" is added to Superman's list of powers.
  • Output: ["Flight", "Super Strength", "Heat Vision"] - It prints the updated array of powers for Superman.
heroProfiles[1].isRich = true;
  • This line adds a new property, "isRich," to the second superhero (Batman) in the heroProfiles array.
  • heroProfiles[1] refers to the second object in the array, which is Batman.
  • .isRich creates a new property "isRich" and assigns it the value true.
  • After this line, the heroProfiles array now has a "isRich" property for Batman.
  • Output: true - It prints true to indicate that Batman is considered rich.

These lines demonstrate how to modify array elements within an array of objects in JavaScript. You can add new elements to arrays (in this case, adding a new power to Superman), and you can also add new properties to objects within the array (in this case, adding the "isRich" property to Batman). This flexibility makes JavaScript a powerful language for working with data and objects.
