What is Matrix in Javascript:

In JavaScript, a matrix is not a built-in data type but is often represented using arrays. A matrix is a two-dimensional array, which means it's an array of arrays, where each sub-array is a row of the matrix.

This data structure is used to store and manipulate data organized in rows and columns, just like a mathematicalmatrix.

Here's how you can create a basic matrix in JavaScript: 


  
const matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
];

In this example, matrix is a 3x3 matrix with three rows and three columns. You can access elements in the matrix using two indices, like matrix[0][1], which refers to the element in the first row (index 0) and the second column (index 1), which is 2 in this case.
If we want to reach number 9 in this matrix we should call it as matrix[2][2] in example

Why Use a Matrix Array Like This?

Here are some fun and understandable examples of why you might want to use a matrix array like heroProfiles:


1. Easy Access to Hero Information:

Example: You can easily access specific information about heroes. For instance, if you want to know Wonder Woman's age, you can use heroProfiles[2][2].



  const wonderWomanAge = heroProfiles[2][2]; // Accessing age of Wonder Woman
  console.log(wonderWomanAge); // Output: 500
2. Organized Data:

Example: The matrix format neatly organizes data, making it easy to see each hero's characteristics in a structured way.


3. Grouping Related Data:
Example: All hero information is grouped together in rows, making it easy to add new heroes or remove existing ones. 

// Adding a new hero

// Removing a hero (e.g., Batman)
