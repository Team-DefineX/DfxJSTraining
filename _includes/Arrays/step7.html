Array Mapping in JavaScript: Explained with Examples

Array mapping is a powerful technique in JavaScript that allows you to transform each element of an array into a new value and create a new array with the transformed values. It provides a concise and efficient way to perform operations on array elements and generate a modified array. In this article, we will explore various examples of array mapping using a sample array of hero profiles.

Consider the following array as our starting point:

let heroProfiles = [
  {
    name: "Superman",
    secretIdentity: "Clark Kent",
    powers: ["Flight", "Super Strength"],
    age: 35,
    isHero: true
  },
  {
    name: "Batman",
    secretIdentity: "Bruce Wayne",
    powers: ["Intelligence", "Combat Skills"],
    age: 40,
    isHero: true
  },
  {
    name: "Wonder Woman",
    secretIdentity: "Diana Prince",
    powers: ["Superhuman Strength", "Lasso of Truth"],
    age: 500,
    isHero: true
  }
];
Example 1: Mapping to extract hero names

Let's begin with a simple scenario of mapping the hero profiles to extract only their names. We can achieve this using the map() method, which creates a new array with the results of calling a provided function on every element in the array. 


let heroNames = heroProfiles.map(hero => hero.name);
  console.log(heroNames);
  // Output: ["Superman", "Batman", "Wonder Woman"]

In the above example, the map() method is used to create a new array (heroNames) by iterating over each element of the heroProfiles array. The arrow function hero => hero.name extracts the name property from each hero profile, and the resulting names are included in the new array.

Example 2: Mapping to extract hero powers

Let's map the hero profiles to extract their powers as separate arrays. We can achieve this by using the map() method. 


let heroPowers = heroProfiles.map(hero => hero.powers);
  console.log(heroPowers);
  // Output: [["Flight", "Super Strength"], ["Intelligence", "Combat Skills"], ["Superhuman Strength", "Lasso of Truth"]]

In the above example, the arrow function hero => hero.powers extracts the powers property from each hero profile, and the resulting power arrays are included in the new array heroPowers. These examples demonstrate how array mapping can be used with the heroProfiles array to transform each element into a new value. The map() method simplifies the process by creating a new array with the mapped values, allowing you to perform operations on array elements in a concise and efficient manner.

Example 3: Mapping to calculate hero ages in dog years

Let's now consider mapping the hero profiles to calculate their ages in dog years. We can achieve this by modifying the mapping operation in the map() method. 


let dogYearsAges = heroProfiles.map(hero => hero.age * 7);
  console.log(dogYearsAges);
  // Output: [245, 280, 3500]

In the above example, the arrow function hero => hero.age * 7 multiplies each hero's age by 7 to calculate their age in dog years, and the resulting values are included in the new array dogYearsAges.

Example 4: Mapping to calculate hero power levels

Let's map the hero profiles to calculate their power levels based on the number of powers they possess. We can achieve this by using a combination of array mapping and reducing the powers array. 


let heroPowerLevels = heroProfiles.map(hero => {
    let powerLevel = hero.powers.length * 10;
    return {
      name: hero.name,
      powerLevel: powerLevel
    };
  });
  console.log(heroPowerLevels);
  /* Output:
  [
    { name: "Superman", powerLevel: 20 },
    { name: "Batman", powerLevel: 20 },
    { name: "Wonder Woman", powerLevel: 20 }
  ]
*/

In this example, we use the map() method to iterate over each hero profile. For each hero, we calculate their power level by multiplying the length of their powers array by 10. We then create a new object containing the hero's name and power level, which is included in the heroPowerLevels array.

Example 5: Mapping to capitalize hero names

Let's map the hero profiles to capitalize the names of the heroes. We can achieve this by using the map() method along with string manipulation methods. 


let capitalizedNames = heroProfiles.map(hero => {
    let capitalized = hero.name.toUpperCase();
    return {
      ...hero,
      name: capitalized
    };
  });
  console.log(capitalizedNames);
  /* Output:
  [
    { name: "SUPERMAN", secretIdentity: "Clark Kent", powers: ["Flight", "Super Strength"], age: 35, isHero: true },
    { name: "BATMAN", secretIdentity: "Bruce Wayne", powers: ["Intelligence", "Combat Skills"], age: 40, isHero: true },
    { name: "WONDER WOMAN", secretIdentity: "Diana Prince", powers: ["Superhuman Strength", "Lasso of Truth"], age: 500, isHero: true }
  ]
  */

In this example, we use the map() method to iterate over each hero profile. For each hero, we capitalize their name by using the toUpperCase() method. We then create a new object by spreading the original hero profile (...hero), but with the updated capitalized name.

Example 6: Mapping to filter and transform hero powers

Let's map the hero profiles to filter out powers that contain the word "Strength" and transform the remaining powers to lowercase. We can achieve this by using the map() method in combination with the filter() and map() methods. 


let transformedPowers = heroProfiles.map(hero => {
    let filteredPowers = hero.powers.filter(power => power.includes("Strength"));
    let transformed = filteredPowers.map(power => power.toLowerCase());
    return {
      ...hero,
      powers: transformed
    };
  });
  console.log(transformedPowers);
  /* Output:
  [
    { name: "Superman", secretIdentity: "Clark Kent", powers: ["super strength"], age: 35, isHero: true },
    { name: "Batman", secretIdentity: "Bruce Wayne", powers: [], age: 40, isHero: true },
    { name: "Wonder Woman", secretIdentity: "Diana Prince", powers: ["superhuman strength"], age: 500, isHero: true }
  ]
  */

In this example, we use the map() method to iterate over each hero profile. For each hero, we filter the powers array using the filter() method to only keep powers that contain the word "Strength
