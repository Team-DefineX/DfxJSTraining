JavaScript Array Methods and Properties

JavaScript arrays come with a variety of built-in methods and properties that make it easier to work with and manipulate arrays. Here's an overview of some common array methods and properties

1# Mutator Methods: These methods modify the array in place.
  • push(): Adds one or more elements to the end of an array.
  • pop(): Removes the last element from an array and returns that element.
  • shift(): Removes the first element from an array and returns that element.
  • unshift(): Adds one or more elements to the beginning of an array.
2# Accessor Methods: These methods do not modify the array but return some representation of it.
  • concat(): Merges two or more arrays, returning a new array.
  • slice(): Returns a shallow copy of a portion of an array into a new array.
  • join(): Joins all elements of an array into a string.
3# Iteration Methods: These methods iterate through arrays and perform a function on each element.
  • forEach(): Executes a provided function once for each array element.
  • map(): Creates a new array with the results of calling a provided function on every element in the calling array.
  • filter(): Creates a new array with elements that pass a test specified by a function.
4# Mutating Methods: These methods change the contents of an array by removing or replacing existing elements.
  • splice(): Changes the contents of an array by removing or replacing existing elements.
  • fill(): Fills all the elements of an array from a start index to an end index with a static value.
5# Search Methods:
  • indexOf(): Returns the first index at which a given element can be found in the array.
  • lastIndexOf(): Returns the last index at which a given element can be found in the array.
6# Sorting and Transformation Methods:
  • sort(): Sorts the elements of an array in place and returns the sorted array.
  • reverse(): Reverses the order of the elements in an array in place.
Array Properties
  • length: Returns the number of elements in the array.
  • constructor: Returns a reference to the array function that created the object.
  • prototype: Allows you to add properties and methods to an array object.

These methods and properties allow for efficient and effective manipulation, traversal, and modification of arrays in JavaScript. They provide a powerful set of tools for handling collections of data within your code.

findIndex(): Returns the index of the first element in an array that satisfies a provided testing function.
Lets find hero not older than 40.
    
    // Use the findIndex method to find the index of the first hero not older than 40
    let index = heroProfiles.findIndex(hero => hero.age <= 40);
    
    if (index !== -1) {
      console.log(`The first hero not older than 40 is ${heroProfiles[index].name}, at index ${index}`);
    } else {
      console.log("No hero found in the array who is not older than 40.");
    }

    // The first hero not older than 40 is Superman, at index 0
