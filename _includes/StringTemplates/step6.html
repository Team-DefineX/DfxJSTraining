Because the placeholder format $expression has a specific meaning in the template literals, you cannot use the character sequence "$someCharacters" without escaping it.


Let's create a string literal containing the sequence of characters ${abc}: 

    
    const message = `Some weird characters: ${abc}`;

Output 

    
    Uncaught ReferenceError: abc is not defined

Because there is no defined variable named abc, JavaScript considers the value $abc as a placeholder and throws an error when it is immediately placed.


The issue can be resolved by adding a backslash \ before the placeholder-like string \${abc}: 

    
    const message = `Some weird characters: \${abc}`;
    console.log(message);

Output 

    
    Some weird characters: ${abc}

JavaScript sees \${abc} in the template string `Some weird characters: \${abc}` as a sequence of characters rather than a placeholder.


The sequence of characters ${abc and ${ must also be escaped with a backslash \ in addition to ${abc}: 

    
    const message = `Some weird characters: \${abc} \${abc \${`;

    console.log(message); // => 'Some weird characters: ${abc} ${abc ${'

Output 

    
    Some weird characters: ${abc} ${abc ${
