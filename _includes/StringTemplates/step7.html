Character sequences are called JavaScript strings. JavaScript strings automatically turn strings into objects so that primitive strings can also be used with string methods and properties. It is employed to represent and work with the character sequence.


If you want to create a string in JavaScript, there are generally two methods. One way to do this is to place the value in quotes and the other one is to use the new String() syntax. 

    
    let string1 = "Team DefineX";
    console.log(string1);

    let string2 = new String("Team DefineX");
    console.log(string2);

Output 

    
    Team DefineX
    String {'Team DefineX'}

Property


length: The number of characters that are present in the string is returned by this property. When an array is involved, this property will return the number of elements that are currently existing in the array. 

    
    console.log("Team DefineX".length);

Output 

    
    12

Methods

slice(startIndex, endIndex)

This function takes in the "start" and "end" index arguments and returns a substring of the string. It does NOT include the "end" index itself.


"End" is not required; if not given, the slice displays all characters from "start" to the end of the string. 

    
    let str = "Team DefineX";
    console.log(str.slice(0,4));
    console.log(str.slice(5,12));

Output 

    
    Team
    DefineX

substring(startIndex, endIndex)

The characters in a string between the "from" and "to" indexes are returned; "to" is not included. It is presumed that "To" extends to the end of the string if it is left out. 

    
    let str = "Team DefineX";
    console.log(str.substring(5, 12));

Output 

    
    DefineX

substr(start, length)

This function returns the characters in a string starting at "start" and going through "length," the specified number of characters that can be supplied. It is presumed that "length" extends to the end of the string if it is left out. 

    
    let str = "Team DefineX";
    console.log(str.substr(5, 7));

Output 

    
    DefineX

replace(replaceValue, replaceWithValue)

Replaces the part that matches the regular expression (or substring) with the text that was replaced. 

    
    let str = "Team DefineX";
    console.log(str.replace("Team", "The Team"));

Output 

    
    The Team DefineX

replaceAll(regexp | substr , newSubstr | function)

After replacing a given text or a regular expression for each match in the string, this method returns a new string. Once this action is completed, the original string remains untouched. 

    
    let str = "Gökhan Ertaş, Gökhan Ertaş, Ozan Avcular,  İlkay İvrendi, Ediz Agarer";
    console.log(str.replaceAll("Gökhan Ertaş", "Emre Çakır"));

Output 

    
    Emre Çakır, Emre Çakır, Ozan Avcular,  İlkay İvrendi, Ediz Agarer

toUpperCase(stringVariable)

There will be no lowercase characters in the string when this function returns it. 

    
    let str = "Team DefineX";         
    console.log(str.toUpperCase());

Output 

    
    TEAM DEFINEX

toLowerCase(stringVariable)

This will return the string with every character changed to lowercase. 

    
    let str = "Team DefineX";
    console.log(str.toLowerCase());

Output 

    
    team definex

concat(objectOfString)

The text of two strings is combined using this method, which returns a new combined or joined string. Use the concat() function on one string object and pass another string object as a parameter to concatenate two strings. 

    
    let str1 = "Team ";
    let str2 = "DefineX";
    console.log(str1.concat(str2));

Output 

    
    Team DefineX

trim()

By using this function, whitespace is eliminated from a string's two ends. 

    
    let str1 = " Team   DefineX   ";
    // String length
    console.log(str1.length);
    console.log(str1);
    // Trim String length
    console.log(str1.trim().length);
    console.log(str1.trim());

Output 

    
    18
      Team   DefineX   
    14
    Team   DefineX

trimStart()

By using this technique, whitespace at the start of a string is eliminated. Nothing changes about the string's value, not even the whitespace that comes after the string. 

    
    let str1 = "  Team DefineX";
    // String length
    console.log(str1.length);
    console.log(str1);
    // TrimStart String length
    console.log(str1.trimStart().length);
    console.log(str1.trimStart());

Output 

    
    14
      Team DefineX
    12
    Team DefineX

trimEnd()

Using this technique, white space at the end of a string is eliminated. Nothing changes about the string's value—not even the white space that comes before the string. 

    
    let str1 = "Team DefineX   ";
    // String length
    console.log(str1.length);
    console.log(str1);
    // Trim String length
    console.log(str1.trimEnd().length);
    console.log(str1.trimEnd());

Output 

    
    15
    Team DefineX   
    12
    Team DefineX

padStart()

In order to get the desired length, this approach pads a string with another string. The left end of the string is where the padding is applied. 

    
    let str = "Team DefineX";
    console.log(str.padStart(14,"*"));

Output 

    
    **Team DefineX

padEnd()

In order to get the desired length, this approach pads a string with another string. The right end of the string is where the padding is applied. 

    
    let str = "Team DefineX";
    console.log(str.padEnd(15,"*"));

Output 

    
    Team DefineX***

charAt(indexOfCharacter)

This function will return the character at the x position within the string. 

    
    let str = "Team DefineX";
    console.log(str.charAt(1)); 
    console.log(str.charAt(11));

Output 

    
    e
    X

charCodeAt(indexOfCharacter)

The character's unicode value at position 'x' in the string will be returned by this function. 

    
    let str = "Team DefineX";
    console.log(str.charCodeAt(1)); 
    console.log(str.charCodeAt(11));

Output 

    
    101
    88

split(character)

The string is divided into an array of substrings using this approach. An array is returned by this procedure. The character you wish to split the string on is the only parameter that this function takes. 

    
    let str = "Team DefineX";
    console.log(str.split(" "));
    console.log(str.split(" ").length);

Output 

    
    ['Team', 'DefineX']
    2
