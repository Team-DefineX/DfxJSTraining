Template literals were added to the JavaScript language in the 2015 edition of the ECMAScript specification (ES6). Using placeholders to embed expressions in a string and constructing multi-line strings more quickly are just two of the significant new features added by template literals, a new way to create strings in JavaScript. In addition, you can operate on the expressions included in a string thanks to a sophisticated feature called tagged template literals. Developers now have more options for manipulating strings because all of these features help you create dynamic strings that may be utilized in functions that edit HTML components or for URLs.
