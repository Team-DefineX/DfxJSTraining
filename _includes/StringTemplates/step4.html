The + operator was used prior to JavaScript ES6 to concatenate variables and expressions into a string. For instance, 

    
    const company = 'Team DefineX';
    const training = 'Javascript Training'
    console.log('Welcome to ' + company + ' ' + training);

Output: 

    
    Welcome to Team DefineX Javascript Training.

An expression can be embedded into a placeholder using template literals. A placeholder is denoted by the symbol ${}, with anything inside the curly brackets being interpreted as JavaScript and everything outside of them as a string: 

    
    const company = 'Team DefineX';
    const training = 'Javascript Training'
    const literalString = `Welcome to ${company} ${training}.`

The following is displayed on the console when literalString is logged there: 

    
    Welcome to Team DefineX Javascript Training.

The creation of dynamic URLs is a usual means of embedding values in a string. This can be difficult with concatenation. For instance, the function to generate an OAuth access string is declared as follows: 

    
    function createOAuthString(host, clientId, scope) {
        return host + '/login/oauth/authorize?client_id=' + clientId + '&scope=' + scope
    }
  
    createOAuthString('https://github.com', 'abc123', 'repo,user')

The following URL will appear in the console after this function is logged: 

    
    https://github.com/login/oauth/authorize?client_id=abc123&scope=repo,user

String interpolation eliminates the need to remember where to place the concatenation operator and the opening and closing strings. The similar example with template literals is shown here: 

    
    function createOAuthString(host, clientId, scope) {
        return `${host}/login/oauth/authorize?client_id=${clientId}&scope=${scope}`
    }

    createOAuthString('https://github.com', 'abc123', 'repo,user')

This will produce the same results as the concatenation example: 

    
    https://github.com/login/oauth/authorize?client_id=abc123&scope=repo,user

Not simply variables but also entire expressions, like the sum of these two values, can be interpolated: 

    
    const multiply = (x, y) => x * y
    const x = 10
    const y = 77
    const literalString = `The multiply of ${x} and ${y} is ${multiply(x, y)}.`

    console.log(literalString)

The function multiply as well as the variables x and y are defined in this code, which then applies both to a string. The following will be displayed in the log result: 

    
    The multiply of 10 and 77 is 770.

This is especially helpful when using ternary operators, which permit conditionals inside of strings: 

    
    const age = 19
    const message = `You are ${age < 21 ? 'not' : ''} authorized to view this page`
    console.log(message)

Depending on whether the value of age is over or under 21, the logged message will change. In this case, it is 19, so the output will be logged as follows: 

    
    You are not authorized to view this page
