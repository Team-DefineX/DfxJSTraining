The methods for declaring strings with single quotes and double quotes are covered in this section, and you will then learn how to declare the same in template literals.


A string can be written in JavaScript using single quotes (' ') 

    
    const singleQuoted  = 'Houston, we have a problem. - Jim Lovell'

A string is also possible to be provided in double quotes (" ") 

    
    const doubleQuoted = "If you want something done right, do it yourself. - Charles-Guillaume Étienne"

In contrast to other languages that may support interpolation in one type of string but not the other, there is no significant difference in JavaScript between single-quoted and double-quoted strings. Interpolation in this sense refers to the assessment of a placeholder as a dynamic component of a string.


While using single- or double-quoted strings largely depends on choice, each form of string only has to escape a specific kind of quote when used together: 

    
    // Escaping a single quote in a single-quoted string
    const singleQuoted = '"We don\'t need anything, we only need a thing; we must be more diligent." - Mustafa Kemal Atatürk'
    
    // Escaping a double quote in a double-quoted string
    const doubleQuoted = "\"We don't need anything, we only need a thing; we must be more diligent.\" - Mustafa Kemal Atatürk"
    
    console.log(singleQuoted);
    console.log(doubleQuoted);

Output: 

    
    "We don't need anything, we only need a thing; we must be more diligent." - Mustafa Kemal Atatürk
    "We don't need anything, we only need a thing; we must be more diligent." - Mustafa Kemal Atatürk

In contrast, template literals are written by enclosing the string in the grave accent (`)or backtick character. 

    
    const stringTemplates = `I think therefore I am. - Rene Descartes`

Output: 

    
    I think therefore I am. - Rene Descartes

They don’t necessarily need to escape single or double quotations. 

    
    const stringTemplates = `"We don't need anything, we only need a thing; we must be more diligent." - Mustafa Kemal Atatürk`

Output: 

    
    "We don't need anything, we only need a thing; we must be more diligent." - Mustafa Kemal Atatürk

They still have to escape backticks, though. 

    
    const stringTemplates = `Template literals use the \` character.`

Output: 

    
    Template literals use the ` character.
