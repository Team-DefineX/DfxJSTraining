In JavaScript, a subclass is a class that is derived from another class, referred to as the superclass or base class. Subclasses inherit the properties and methods of the superclass, and they can also have their own unique properties and methods. Subclasses are used to create a more specialized version of a class, allowing you to build on the functionality of the base class while maintaining a clear hierarchical structure. This is known as class inheritance.


Here's an explanation with example code based on the provided SuperVillainProfile class, which is a subclass of the HeroProfile class:


Defining a Subclass: 

class SuperVillainProfile extends HeroProfile {
  constructor(name, age, power, evilPlan) {
    // Call the constructor of the parent class using super().
    super(name, age, power);
    this.evilPlan = evilPlan;
  }

  // Override the usePower() method from the parent class.
  usePower() {
    console.log(`${this.name} uses ${this.power} to execute their evil plan: ${this.evilPlan}`);
  }

  // New method specific to SuperVillainProfile class.
  revealEvilPlan() {
    console.log(`${this.name}'s evil plan is to ${this.evilPlan}`);
  }
}
  • In this code, SuperVillainProfile is a subclass of the HeroProfile superclass. It inherits the name, age, and power properties and the usePower() method from HeroProfile.
  • The subclass has its own constructor that sets up the properties specific to super villains, such as evilPlan.
  • It overrides the usePower() method to provide a different behavior when a super villain uses their power. In this case, it includes the description of the evil plan.
  • A new method, revealEvilPlan(), is introduced that is specific to the SuperVillainProfile class. It allows super villains to reveal their evil plans.

You can create instances of the SuperVillainProfile subclass and access its methods:


Using the Subclass: 

  // Creating an instance of the SuperVillainProfile class.
  const joker = new SuperVillainProfile('Joker', 35, 'Chaos', 'create anarchy in Gotham City');
  
  // Using methods on the instance.
  joker.introduce(); // Output: "Hi, I'm Joker, and I'm a superhero!"
  joker.displayAge(); // Output: "Joker is 35 years old."
  joker.usePower(); // Output: "Joker uses Chaos to execute their evil plan: create anarchy in Gotham City"
  joker.revealEvilPlan(); // Output: "Joker's evil plan is to create anarchy in Gotham City"

In this example, SuperVillainProfile is a specialized version of the HeroProfile class, and it inherits and extends the properties and methods to represent super villains. Subclasses are useful for creating a hierarchy of classes with shared behavior and specialized features, making your code more organized and maintainable.
