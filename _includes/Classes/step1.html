Classes for JavaScript

Classes are a fundamental part of the language introduced in ECMAScript 6 (ES6) to provide a more structured and object-oriented approach to organizing and defining objects. They allow you to create reusable templates for objects with shared properties and methods. Here are three key details about JavaScript classes:

Let's create a HeroProfile class step-by-step, explaining each part along the way. We'll build upon it to demonstrate class inheritance later.

#1 Class Declaration and Constructor:

First, we'll declare the HeroProfile class and define its constructor. The constructor is a special method that gets called automatically when we create a new instance of the class using the new keyword. It allows us to initialize the properties of the hero. 



class HeroProfile {
  constructor(name, age, power) {
    this.name = name;
    this.age = age;
    this.power = power;
  }
}

In this step, we've defined the HeroProfile class with a constructor that takes three parameters: name, age, and power. The constructor sets these values as properties of the object being created. Lets explain the lines for above code.


  • constructor(name, age, power): This line defines the constructor method with three parameters - name, age, and power. When you create a new HeroProfile object, you'll need to provide values for these parameters.

  • this.name = name;: Inside the constructor, this refers to the newly created object. It is used to assign the values passed as parameters to the object's properties. So, the name parameter is assigned to the name property of the object, and similarly for age and power.
Class Declaration

To declare a class in JavaScript, you use the class keyword followed by the name of the class. In your code, you've declared a class named HeroProfile.


Constructor

Inside the class, you have a special method called the constructor. The constructor is a method that is automatically called when you create a new instance (or object) of the class using the new keyword. It allows you to initialize the properties of the object.


Now, you can create instances of the HeroProfile class and set the properties like this:


const hero1 = new HeroProfile("Superman", 30, "Flight");
const hero2 = new HeroProfile("Batman", 35, "Intelligence");

In this example, hero1 and hero2 are two separate instances of the HeroProfile class, each with its own name, age, and power properties. This allows you to organize and manage data in a structured way and create multiple objects with the same structure and behavior, which is a fundamental concept in object-oriented programming.
