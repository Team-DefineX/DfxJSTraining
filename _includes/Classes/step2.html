Class methods in JavaScript are defined using the static keyword within the class. They are associated with the class itself, rather than with instances (objects) of the class. Class methods are often used for tasks that don't require access to instance-specific data but are related to the class as a whole.


Instance Methods

Instance methods, on the other hand, are not defined with the static keyword and are associated with individual instances of the class. They can access and manipulate instance-specific data.

Next, let's add some methods to the HeroProfile class to perform actions related to the hero. 



class HeroProfile {
  constructor(name, age, power) {
    this.name = name;
    this.age = age;
    this.power = power;
  }

  // Instance method to introduce the hero
  introduce() {
    console.log(`Hi, I'm ${this.name}, and I'm a superhero!`);
  }

  // Instance method to display the hero's age
  displayAge() {
    console.log(`${this.name} is ${this.age} years old.`);
  }

  // Instance method to display the hero's power
  usePower(hero) {
    console.log(`${hero.name} uses ${hero.power}!`);

  // Class method to explain what superheroes do
  static explainHeroics() {
    console.log("Superheroes protect and serve the world!");
  }

  // Class method to provide a superhero motto
  static superheroMotto() {
    console.log("With great power comes great responsibility!");
  }
}

In this step, we've added three inheritance methods to the HeroProfile class: introduce(),displayAge()andusePower(). These methods allow us to introduce the hero, display their age, and use their power, respectively. Also we created a Class Method as explainHeroics() to explain what an superhero does generally.


Instance Methods:
  1. Instance methods are defined without the static keyword within the class.
  2. They operate on instance-specific data and are called on instances of the class.
Class Methods
  1. Class methods are defined using the static keyword within the class.
  2. They are associated with the class itself, not instances.
  3. Class methods are used for actions related to the class as a whole, not to specific instances.

Now, you can create instances of the HeroProfile class and use these methods to interact with the hero's profile: 



// Create instances of HeroProfile
const superman = new HeroProfile("Superman", 30, "Flight");
const batman = new HeroProfile("Batman", 35, "Intelligence");

// Using instance methods
superman.introduce(); // "Hi, I'm Superman, and I'm a superhero!"
superman.displayAge(); // "Superman is 30 years old."
superman.usePower(); // "Superman uses Flight!"

// Using class method
HeroProfile.explainHeroics(); // "Superheroes protect and serve the world!"
HeroProfile.superheroMotto(); // "With great power comes great responsibility!"

introduce()and displayAge() are instance methods because they operate on specific instances (superman and batman).


explainHeroics() and superheroMotto() is a class method because it is called on the HeroProfile class itself and is common to all instances of the class.


This distinction allows you to define and use methods that are either specific to individual instances or shared among all instances of the class, making your code more organized and modular.


Getters & Setters

Getters and setters allow controlled access to object properties, enabling additional logic or validation when getting or setting values.

Getters: Getters are methods used to retrieve the value of a property. They are defined using the get keyword followed by the property name. When the property is accessed, the associated getter function is called automatically.

Setters: Setters are methods used to assign a value to a property. They are defined using the set keyword followed by the property name. When a value is assigned to the property, the associated setter function is called automatically.

Let's add getters and setters for the age property in the HeroProfile class. 



class HeroProfile {
  constructor(name, age, power) {
    this.name = name;
    this._age = age; // Use an underscore for the private property
    this.power = power;
  }

  // Instance method to introduce the hero
  introduce() {
    console.log(`Hi, I'm ${this.name}, and I'm a superhero!`);
  }

  // Getter for age
  get age() {
    return this._age;
  }

  // Setter for age
  set age(newAge) {
    if (newAge > 0 && newAge < 150) {
      this._age = newAge;
    } else {
      console.error('Invalid age!');
    }
  }

  // Instance method to display the hero's age
  displayAge() {
    console.log(`${this.name} is ${this.age} years old.`);
  }

  // Instance method to display the hero's power
  usePower() {
    console.log(`${this.name} uses ${this.power}!`);
  }

  // Class method to explain what superheroes do
  static explainHeroics() {
    console.log("Superheroes protect and serve the world!");
  }

  // Class method to provide a superhero motto
  static superheroMotto() {
    console.log("With great power comes great responsibility!");
  }
}

get age() defines a getter method for the age property, allowing us to retrieve the value of age using heroInstance.age


set age(newAge) defines a setter method for the age property, allowing us to set the age value using heroInstance.age = newAge.
It includes validation to ensure the age is within a reasonable range (0 to 150 years). If the age is invalid, it logs an error message.


These getters and setters provide controlled access to the age property, allowing for additional logic or validation during the retrieval or assignment of the age value within the HeroProfile class.



// Creating an instance of HeroProfile and using the getter and setter
const hero = new HeroProfile('Spider-Man', 20, 'Web-slinging');

hero.introduce(); // Output: Hi, I'm Spider-Man, and I'm a superhero!
hero.displayAge(); // Output: Spider-Man is 20 years old.

// Using the setter to update the age
hero.age = 25; // Valid age assignment

// Attempting to set an invalid age
hero.age = 200; // Output: Invalid age!

hero.displayAge(); // Output: Spider-Man is 25 years old.
hero.usePower(); // Output: Spider-Man uses Web-slinging!

In this example, the age property is accessed and modified using the getter (hero.age) and setter (hero.age =newAge).
The setter ensures that the age is within a valid range when updated, providing additional control over the modification of the age property.
