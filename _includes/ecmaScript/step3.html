Switching from es6 to es5

1) Babel Load
First, you need to add Babel to your project. Babel, ES6 (and newer JavaScript versions) code to ES5. npm or yarn the following packages to install Babel You can add it to your project using 
    
    npm install --save-dev @babel/core @babel/preset-env babel-loader
2) Webpack Configuration
You will need to make some changes to your webpack config file.
  • Adding Babel Loader: Add Babel Loader to your Webpack config file. Babel Loader with webpack used with Babel to convert JavaScript files in your project.
  • Preset Settings: When using Babel Loader, you must use the @babel/preset-env preset. This, It will give instructions to convert Babel to ES5.
        
        module: {
            rules: [
                {
                test: /\.js$/,
                exclude: /node_modules/,
                use: {
                    loader: 'babel-loader',
                    options: {
                    presets: ['@babel/preset-env']
                    }
                }
                }
            ]
            }
3) .babelrc
To specify how Babel will behave, add the .babelrc file to your project's root directory. In this file the following You can use the content: 
    
        {
            "presets": ["@babel/preset-env"]
        }

In other hand, if we dont use this way we can add ES6 features manually. For example, Math.trunc(n) is a function that “cuts off” the decimal part of a number, e.g Math.trunc(1.23) returns 1.

In some (very outdated) JavaScript engines, there’s no Math.trunc, so such code will fail.

As we’re talking about new functions, not syntax changes, there’s no need to transpile anything here. We just need to declare the missing function.

A script that updates/adds new functions is called “polyfill”. It “fills in” the gap and adds missing implementations.

For this particular case, the polyfill for Math.trunc is a script that implements it, like this:

    
      if (!Math.trunc) { 
        Math.trunc = function(number) {
          return number < 0 ? Math.ceil(number) : Math.floor(number);
        };
      }

JavaScript is a highly dynamic language. Scripts may add/modify any function, even built-in ones.

You can use that site. You can manage your custom polyfills in here.
