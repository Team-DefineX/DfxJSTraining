ES6 (ECMAScript 2015)

It is the sixth version of JS released in 2015. ES6, a big language is the development and added many new features. Notable innovations include block scope variables (let and const), arrow functions, rest and spread operators, classes, modules, Promise, arrow functions and There are many features such as destructuring. These new features make code cleaner, readable and makes it sustainable.
