JavaScript (JS), web tarayıcılarında çalışan bir programlama dilidir. JS, dinamik ve etkileşimli web sayfaları oluşturmak için kullanılır. Aynı zamanda sunucu tarafında da (Node.js kullanarak) uygulama geliştirme imkanı sağlar.

JS, web tarayıcılarında çalıştığı için, kullanıcının etkileşimde bulunabildiği öğeleri (HTML elementleri gibi) kontrol etmek ve işlemek için kullanılır. Örneğin, bir butona tıklandığında bir işlem gerçekleştirmek, form verilerini doğrulamak veya bir animasyon oluşturmak için JS kullanılabilir.

ES5 (ECMAScript 5) ve ES6 (ECMAScript 2015), JS'in farklı sürümleridir. ES5, 2009 yılında yayınlanmıştır ve o zamandan beri en yaygın olarak kullanılan JS sürümü olmuştur. ES6 ise 2015 yılında yayınlanmıştır ve JS'e bir dizi yeni özellik eklemiştir.

ES6 (ECMAScript 2015)

2015 yılında yayınlanan JS'in altıncı sürümüdür. ES6, büyük bir dil geliştirmesidir ve birçok yeni özellik eklemiştir. Öne çıkan yenilikler arasında blok kapsamı değişkenleri (let ve const), ok fonksiyonları, rest ve spread operatörleri, sınıflar, modüller, Promise, arrow fonksiyonlar ve destructuring gibi birçok özellik bulunur. Bu yeni özellikler, kodun daha temiz, okunabilir ve sürdürülebilir olmasını sağlar.

es6 uygulamayı es5 e çalıştırma adımları

1)Babel Kurulumu
Öncelikle, Babel'ı projenize eklemeniz gerekmektedir. Babel, ES6 (ve daha yeni JavaScript sürümleri) kodunu ES5'e dönüştürmek için kullanılır. Babel'ı yüklemek için aşağıdaki paketleri npm veya yarn kullanarak projenize ekleyebilirsiniz 
        
        npm install --save-dev @babel/core @babel/preset-env babel-loader
2)Webpack Yapılandırması
Webpack yapılandırma dosyanızda bazı değişiklikler yapmanız gerekecektir.
  • Babel Loader Ekleme: Webpack yapılandırma dosyanıza Babel Loader'ı ekleyin. Babel Loader, webpack ile birlikte kullanıldığında Babel'ı projenizdeki JavaScript dosyalarını dönüştürmek için kullanır.
  • Preset Ayarları: Babel Loader'ı kullanırken, @babel/preset-env ön ayarını kullanmanız gerekmektedir. Bu, Babel'a ES5'e dönüştürme talimatlarını verecektir.
          
            module: {
                rules: [
                  {
                    test: /\.js$/,
                    exclude: /node_modules/,
                    use: {
                      loader: 'babel-loader',
                      options: {
                        presets: ['@babel/preset-env']
                      }
                    }
                  }
                ]
              }
3) .babelrc ayarlanması
Babel'ın nasıl davranacağını belirtmek için .babelrc dosyasını projenizin kök dizinine ekleyin. Bu dosyada aşağıdaki içeriği kullanabilirsiniz: 

            {
                "presets": ["@babel/preset-env"]
              }
