ES5 (ECMAScript 5) and ES6 (ECMAScript 2015) are different versions of JS. ES5 was released in 2009 and it has been the most widely used JS version ever since. ES6, on the other hand, was released in 2015 and is implemented in JS. added a number of new features.

What's new in ECMAScript 5

"use strict": We can use strict mode in all our programs. It helps us to write cleaner code, like preventing us from using undeclared variables. 

                
                "use strict";
                x = 3.14;              // Error
                x = {p1:10, p2:20};    // Error

                let a = 2023;
                delete a;               // Error

                function x(p1, p2) {};
                delete x;               // Error

                function x(p1, p1) {};  // Error

ForEach: The forEach() method calls a function once for each array element.

                numbers.forEach(myFunction);

                function myFunction(value, index, array) {

                }

Convert Anything to Boolean

In addition to true and false, JavaScript treats other types as truthy or falsy. 0, "", null, undefined, NaN, and false are always falsy. Everything else is truthy. Because of this, in JavaScript, you can convert any values to true and false with the unary operator (!): 
                                    
                                        const bool1 = !0;        // true
                                        const bool2 = !100;      // false
                                        const bool3 = !"test";   // false
                                        const bool4 = !!"test";  // true

Map: It will create a new array based on the origin array.

                var numbers2 = numbers1.map(myFunction);

                function myFunction(value, index, array) {
                    return value * 2;
                }

Filter: It will create a new array from condition with the origin array.

            
                var numbers = [45, 4, 9, 16, 25];
                var over18 = numbers.filter(myFunction);

                function myFunction(value) {
                return value > 18;
                }

Reduce: It runs a function on each array element to produce (reduce it to) a single value. It works from left-to-right in the array. And it does not reduce the original array. 

            
                // Wont update original array
                // Return single value
                const numbers = [45, 4, 9, 16, 25];
                let sum = numbers.reduce(myFunction);

                function myFunction(total, value, index, array) {
                    return total + value;
                }

Every: It will check if all array elements satisfy a condition. The returned value is true or false. 

            
                const numbers = [45, 4, 9, 16, 25];
                let allOver18 = numbers.every(myFunction);

                function myFunction(value, index, array) {
                    return value > 18;
                }

Some
