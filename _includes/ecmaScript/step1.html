Convert Anything to Boolean

In addition to true and false, JavaScript treats other types as truthy or falsy. 0, "", null, undefined, NaN, and false are always falsy. Everything else is truthy. Because of this, in JavaScript, you can convert any values to true and false with the unary operator (!): 
                                    
                                        const bool1 = !0;        // true
                                        const bool2 = !100;      // false
                                        const bool3 = !"test";   // false
                                        const bool4 = !!"test";  // true

Reduce: It runs a function on each array element to produce (reduce it to) a single value. It works from left-to-right in the array. And it does not reduce the original array.

                // Return single value

                let sum = numbers.reduce(myFunction);

                function myFunction(total, value, index, array) {
                    return total + value;
