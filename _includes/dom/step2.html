Performance

Less DOM Operation

DOM operations are costly operations. Instead of doing too many DOM operations, consider combining multiple operations. For example, instead of adding one large piece of HTML to the DOM in multiple operations, first combine all the content and then insert it in one operation.

Optimized Selectors

DOM selectors (querySelector, getElementById, etc.) can be slow. Avoid too complex selectors and use specific selectors whenever possible. It is faster to select elements based on unique attributes such as class and id.

Collections Usage

DOM collections (for example, getElementsByClassName, getElementsByTagName) are live and updated each time they are called. So it's more efficient to store these collections in a variable beforehand and avoid unnecessary repetitions.

Display: None

Display: none creates an element on DOM. If you can please no add element to DOM. If you cant , you can manage those issue via class.

Update one time ( And Reflow veya Layout Thrashing )

If you're going to make multiple DOM changes, do them in bulk. For example, if you are going to change the style of an element, instead of directly changing the style property, you can make changes in bulk by adding and removing a class from the element.
