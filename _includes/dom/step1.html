The HTML DOM (Document Object Model)

When a web page is loaded, the browser creates a Document Object Model of the page. HTML DOM, XML DOM and SVG DOM are main DOM types. We will cotinue with HTML DOM. Each is used for a specific type of document and programmatically provides access to the document's content.

Function Declaration

DOM stands for Document Object Model. It is a programming interface that represents the structural representation of a web page. It allows web browsers to understand and interactively manipulate the content of a web page. The DOM represents HTML or XML documents in a tree-like structure, enabling browsers or other programs to access and modify their content, style, and structure.

The DOM represents every element on a web page (e.g., headings, paragraphs, images, buttons, etc.) as objects. These objects are associated with each other in a tree structure. The root of the tree represents the main document object, and through this object, other elements can be accessed.

For web development, the DOM is an API provided by browsers and can be accessed using programming languages like JavaScript. The DOM API provides a set of methods and properties to access elements on web pages, add, remove, or modify elements, apply styles, listen for and handle events, and perform various other operations.

In summary, the DOM is a programming interface that enables the programming and dynamic manipulation of web pages through web browsers.

DOM partials

  • Elements: The name of the html element.
  • Text: The number of named parameters the function expects.
  • Attribute: Returns the source code of the function as a string.
Elements selection
  • getElementById: Get element with id attribute. document.getElementById("id")
  • getElementsByClassName: Get element with class name. document.getElementsByClassName("class")
  • getElementsByTagName: Get element with tag name. document.getElementsByTagName("div")
  • querySelector: Returns the first selected element. document.querySelector("#myElement") , document.querySelector(".myElement"), document.querySelector("div"), document.querySelector("#myElement .class div")
  • querySelectorAll: Returns the array and ıt store all selected elements. document.querySelectorAll(".myClass")

Attribute

    
        const att = document.createAttribute("class");
        att.value = "democlass";

        const h1 = document.getElementsByTagName("H1")[0];

Text node

Actions
Click

We can change DOM via javascript. we have some ways to use.

        
        <button id="myButton">Tıkla
        <script>
            const button = document.getElementById('myButton');   // select element
            button.addEventListener('click', function() {  // // click event
                alert('Butona tıklandı!');
            });
        </script>
        <script>
            button.addEventListener('dblclick', function() {  // double click event
                myDiv.style.backgroundColor = 'blue';
            });
        </script>
KeyDown&KeyUp Event
        
        <button id="myButton">Tıkla
        <input type="text" id="myInput">
        <script>
            const myInput = document.getElementById('myInput');   // select element
            myInput.addEventListener('keydown', function(event) {  // Add Listener
                if (event.key === 'Enter') {
                alert('Enter tuşuna basıldı!');
                }
            });
        </script>
        <script>
            myInput.addEventListener('keyup', function(event) { // Add listener
                console.log('Basılan Tuş:', event.key);
            });
        </script>
Mousemove Event
        
        <button id="myButton">Tıkla
        <div id="myDiv" style="width: 100px; height: 100px; background-color: red;"></div>
        <script>
            const myDiv = document.getElementById('myDiv');
            myDiv.addEventListener('mousemove', function(event) {
                const x = event.clientX;
                const y = event.clientY;
                console.log('X:', x, 'Y:', y);
            });
        </script>
Submit Event
        
        <form id="myForm">
        <input type="text" name="username">
        <input type="password" name="password">
        <button type="submit">Gönder </button>
        </form>
        <script>
            const myForm = document.getElementById('myForm');
            myForm.addEventListener('submit', function(event) {
                event.preventDefault();
                const formData = new FormData(myForm);
                const username = formData.get('username');
                const password = formData.get('password');
                console.log('Kullanıcı Adı:', username, 'Şifre:', password);
            });
        </script>
