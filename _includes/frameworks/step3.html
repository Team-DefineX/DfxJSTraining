React ToDo 
    
        import React, { useState } from 'react';

        const TodoApp = () => {
            const [todos, setTodos] = useState([]);
            const [inputValue, setInputValue] = useState('');

            const handleInputChange = (e) => {
                setInputValue(e.target.value);
            };

            const addTodo = () => {
                if (inputValue.trim() !== '') {
                setTodos([...todos, inputValue]);
                setInputValue('');
                }
            };

            const removeTodo = (index) => {
                const newTodos = [...todos];
                newTodos.splice(index, 1);
                setTodos(newTodos);
            };

            return (
                <div>
                <h1>Todo App</h1>
                <input type="text" value={inputValue} onChange={handleInputChange} />
                <button onClick={addTodo}>Add Todo</button>
                <ul>
                    {todos.map((todo, index) => (
                        <li key={index}>
                            {todo} <button onClick={() => removeTodo(index)}>Remove</button>
                        </li>
                    ))}
                </ul>
                </div>
            );
        };

export default TodoApp;

In the examples above, we created a simple todo app for all three frameworks. These examples show the different syntax and structure of React, Angular, and Vue.js, but they basically have the same functionality. You can further develop these applications in your own project and add different features.

LifeCycles:
React allows components to be class-based (class) or function-based (functional) and can use Hooks for lifecycle management. Angular defines components as TypeScript classes and has special lifecycle methods like ngOnChanges, ngOnInit, ngOnDestroy. Vue.js defines components as JavaScript objects or functions and also has custom lifecycle methods (beforeCreate, mounted, destroyed, etc.).

State ve Data Management:
React uses props and state for state management and encourages not modifying state directly. Angular generally takes a one-way data binding approach and uses the @Input and @Output decorators to facilitate data flow between components. Vue.js uses v-model to provide two-way data binding and also supports one-way data flow.
