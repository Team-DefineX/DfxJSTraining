JavaScript frameworks are tools created to help developers build web applications more quickly, efficiently and sustainably. Reasons for creating these frameworks
Reduction of Code Repetition: Web development process may require repeating certain tasks repeatedly. This can lead to a waste of time and error risk. Frameworks reduce this repetition and allow developers to achieve more by writing less code.
Structure and Organization: It is inevitable that large -scale web applications become complex. Frameworks standardizing project configuration and code organization, preventing the loss of control as it grows.
Efficiency and Speed: Frameworks accelerate the development process by providing predefined components and features. This helps to complete the application faster.
Mobile Compliance: Since mobile devices are increasingly used, it is important that web applications work properly on mobile devices. Some frameworks offer pre -optimized components to ensure mobile compliance.
Community and Support: Popular frameworks often have a large and active developer community. These communities provide a platform to solve problems, help and share the best practices.

First Contentfull Paint: This metric measures how long it takes from the user initiating the load until the any html element is rendered within the viewport. React wins this metric with a score of 60%.
Largest Contentfull Paint: This metric measures how long it takes from the user initiating the load until the largest text image, block, or video is rendered within the viewport. React wins this metric with a score of 60%.
Cumulative Layout Shift: This metric measures the movements of the page as content renders or new content is shown on the page. React wins this metric with a score of 72%.
First Input Delay: This metric measures the time from the moment the user first interacts with a page until the moment the browser can actually start processing event handlers in response to that interaction. Vue & Angular win this metric with a score of 87%.
Time To First Byte: This metric measures allmost nothing for React-Angular-Vue Because we can improve this metric in server or other backend layer.

Shadow DOM (Shadow Document Object Model) is a technology for isolating the content and style of web components. This makes web components more manageable and reusable, while helping to avoid conflicting browser content and style conflicts. Shadow DOM is a concept that underlies many modern web frameworks.
