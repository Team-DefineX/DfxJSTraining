In JavaScript, closure refers to the combination of a function and the lexical environment within which that function was declared. It allows a function to access variables from its outer scope even after the outer function has finished executing. Closures are a powerful concept that enables more advanced programming techniques and can be used to create private variables and data encapsulation.

How Closure Works

When a function is defined, it forms a closure along with its lexical environment. The closure consists of the function itself and the references to all variables and functions that were in scope at the time of its creation. This means that even if the outer function is no longer executing, the inner function still retains access to the variables and functions from its parent scope.

Example
    
    function outerFunction() {
        const outerVariable = 'I am from outer function';
        
        function innerFunction() {
            console.log(outerVariable);
        }
        return innerFunction;
    }
    
    const inner = outerFunction();
    inner(); // Output: I am from outer function

Closures are commonly used for maintaining private variables and creating encapsulated modules in JavaScript. They allow you to control the visibility and lifetime of variables, preventing them from being accessed or modified from outside the function.

Understanding closures is important for writing more advanced JavaScript programs and leveraging powerful programming techniques.

More JavaScript Closure example
    
        function counter() {
            var count = 0;
            
            function increment() {
                count++;
                console.log(count);
            }

            function decrement() {
                count--;
                console.log(count);
            }

            return {
                increment: increment,
                decrement: decrement
            };
        }
        
        var counterObj = counter();
        counterObj.increment(); // Output: 1
        counterObj.increment(); // Output: 2
        counterObj.decrement(); // Output: 1

Closures are powerful in scenarios where you need to maintain state or encapsulate data within functions. They provide a way to create private variables and define functions that can access and manipulate those variables. Closures enable you to create modular and reusable code, enhancing the flexibility and functionality of your JavaScript programs.

Tasks

Create a function called "calculator". This function should take a starting value as a parameter and return inner functions capable of performing four basic arithmetic operations. The inner functions should be named "add", "subtract", "multiply", and "divide", and each of them should take two parameters to perform the respective operation.

Expected Output:

    console.log(calc.subtract(2)); // Expected Output: 6
    console.log(calc.multiply(4)); // Expected Output: 24
    console.log(calc.divide(2)); // Expected Output: 12
