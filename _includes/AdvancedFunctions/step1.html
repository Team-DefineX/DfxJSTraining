In JavaScript, functions are first-class objects, which means they can be assigned to variables, passed as arguments to other functions, and returned from functions. Understanding the function type and its properties and methods is essential for working with functions effectively.

Function Declaration

The most common way to define a function is through function declarations. Here's an example:

    
    const greeting = function(name) {
        console.log(`Hello, ${name}!`);
    };

    greeting("Aslan"); // Output: Hello, Aslan!

In this example, we declare a function named greet that takes a name parameter and logs a greeting message to the console.

Function Expression

Another way to define functions is through function expressions. Here's an example:


    const greet = function (name) {
        console.log(`Hello, ${name}!`);
    };

    greet('Jane'); // Output: Hello, Jane!

In this case, we assign an anonymous function to the greet variable using a function expression.

Function Properties and Methods

Functions in JavaScript are objects and, as such, have built-in properties and methods. Some commonly used properties and methods of functions include:

  • name: The name of the function.
  • length: The number of named parameters the function expects.
  • toString(): Returns the source code of the function as a string.

    function sayHello() {
        console.log('Hello!');
    }

    console.log(sayHello.name); // Output: sayHello
    console.log(sayHello.length); // Output: 0
    console.log(sayHello.toString()); // Output: function sayHello() { console.log('Hello!'); }
Function Invocation

Functions can be invoked using the function call syntax or the function apply syntax. Here's an example:


    function greet(name) {
    console.log(`Hello, ${name}!`);
    }

    greet.call(null, 'Michael'); // Output: Hello, Michael!
    greet.apply(null, ['Sarah']); // Output: Hello, Sarah!

In the above code, call and apply are used to invoke the greet function, passing the name parameter.

Understanding the function type in JavaScript is fundamental to effectively work with functions and leverage their versatility. It allows you to create reusable code, encapsulate logic, and build complex applications.

new.target

The new.target is a special meta property in JavaScript that allows you to determine whether a function or constructor was called with the new keyword. It provides information about the target of the new operator within the function body.

Here are a few key points about new.target:

  1. Usage: new.target is accessed within the body of a function or constructor and returns a reference to the constructor or function that was directly invoked with new. It is undefined if the function was not called with new.
  2. Constructor Functions: When a constructor function is invoked with new, new.target refers to the constructor function itself. This allows you to perform specific actions or customize behavior based on whether the function was invoked as a constructor or a regular function. 
    3.         
            function sayHello() {
                console.log('Hello!');
            }
        
            console.log(sayHello.name); // Output: sayHello
            console.log(sayHello.length); // Output: 0
            console.log(sayHello.toString()); // Output: function sayHello() { console.log('Hello!'); }
  3. Inheritance and super: new.target is particularly useful in the context of inheritance and the super keyword. It allows you to access the constructor of the derived class when calling super within a subclass constructor. 
    4.         
            class Parent {
                constructor() {
                    console.log(new.target); // Output: [Function: Child]
                }
            }
            
            class Child extends Parent {
                constructor() {
                    super();
                }
            }
            
            const child = new Child(); // Output: [Function: Child]
  4. Arrow Functions: Arrow functions do not have their own new.target. Instead, they inherit new.target from the surrounding non-arrow function. 
    5.         
            function regularFunction() {
                const arrowFunction = () => {
                    console.log(new.target); // Inherited from regularFunction
                };

                arrowFunction();
            }

            regularFunction(); // Output: [Function: regularFunction]
