What is Express.js?

    Express.js is a minimal and flexible web application framework for Node.js. It is widely used to build RESTful APIs, web applications, and backend services. Express simplifies handling HTTP requests and responses, making web development more efficient.



Why Was Express.js Created?

    Express.js was developed to simplify server-side development with Node.js. The built-in Node.js HTTP module is low-level and requires a lot of boilerplate code. Express provides an abstraction layer that makes it easier to handle routing, middleware, and request/response management.


Key Features of Express.js:

  • Lightweight & Fast: Minimalistic framework with high performance.
  • Middleware Support: Modular structure for handling requests efficiently.
  • Routing System: Handles dynamic routes and HTTP methods easily.
  • Easy REST API Development: Simplifies CRUD (Create, Read, Update, Delete) operations.
  • Third-Party Integrations: Supports plugins like morgan, cors, and body-parser.


Create a Simple Express Server 
  
    const express = require('express');  // Import Express
    const app = express();  // Initialize the app
    const port = 3000;  // Define the port

    app.get('/', (req, res) => {
      res.send('Hello, Express!');
    });

    app.listen(port, () => {
      console.log(`Server running on port ${port}`);
    });
  • express() initializes the application.
  • app.get('/', callback) handles a GET request at /.
  • app.listen(port, callback) starts the server on the specified port.

Handling HTTP Methods (GET, POST, PUT, DELETE) 
  
    const express = require('express');
    const app = express();
    app.use(express.json()); // Middleware to parse JSON requests
    const port = 3000;

    app.get('/users', (req, res) => {
      res.json([
        { id: 1, name: 'John Doe' },
        { id: 2, name: 'Jane Doe' }
      ]);
    });

    app.post('/users', (req, res) => {
      const newUser = req.body; // Get data from request body

      res.status(201)
        .json({
          message: 'User created',
          user: newUser
        });
    });

    app.put('/users/:id', (req, res) => {
      const userId = req.params.id;
      const updatedData = req.body;
      res.json({
        message: `User ${userId} updated`,
        data: updatedData
      });
    });

    app.delete('/users/:id', (req, res) => {
      const userId = req.params.id;
      res.json({
        message: `User ${userId} deleted`
      });
    });

    app.listen(port, () => {
        console.log(`Server running on port ${port}`);
    });


What is Middleware in Express.js?

    Middleware functions process requests before they reach the final route handler. They can modify requests, validate data, log activities, and handle errors.

Global Middleware Example: 

  
    app.use((req, res, next) => {
      console.log(`Request: ${req.method} ${req.url}`);
      next(); // Pass control to the next middleware
    });

Route-Specific Middleware Example: 

  
    const checkAuth = (req, res, next) => {
      const token = req.headers.authorization;
      if (token === 'secret-token') {
        next(); // Continue if authorized
      } else {
        res.status(403).json({ message: 'Forbidden' });
      }
    };

    app.get('/dashboard', checkAuth, (req, res) => {
      res.send('Welcome to the dashboard');
    });

Using Third-Party Middleware Example: 

  
    const morgan = require('morgan'); // Log library
    app.use(morgan('dev')); // Logs every request to the console

Error Handling Middleware Example: 

  
    app.use((err, req, res, next) => {
      console.error(err.stack);
      res.status(500).send('Something went wrong!');
    });
