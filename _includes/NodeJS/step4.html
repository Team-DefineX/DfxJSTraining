What is Next.js?

    Next.js is a React framework that enables features like server-side rendering (SSR), static site generation (SSG), and API routes. It simplifies building fast, scalable, and SEO-friendly web applications.


How Does Next.js Work?

    Next.js pre-renders pages by default, meaning it generates HTML in advance instead of relying only on client-side JavaScript. It can render content on:

  1. Build Time (SSG - Static Site Generation): The HTML is generated at build time and reused for each request.
  2. Request Time (SSR - Server-Side Rendering): The page is generated dynamically on each request.

Next.js also includes an integrated API layer, allowing you to write backend logic within the same project.

What is SSR (Server-Side Rendering)?

Server-side rendering (SSR) means that Next.js generates the HTML for a page on the server at request time, rather than in the browser. This allows:

  • Better SEO (because search engines can see fully rendered pages).
  • Faster initial load time compared to client-side rendering.
  • Fresh data for each request, instead of static content.
Example of an SSR Page: 
  
    import React from 'react';

    export async function getServerSideProps() {
      const res = await fetch('https://jsonplaceholder.typicode.com/posts/1');
      const data = await res.json();

      return { props: { post: data } };
    }

    export default function Post({ post }) {
      return (
         <div>
           <h1>{post.title}</h1>
           <p>{post.body}</p>
         </div>
      );
    }

Here, getServerSideProps() fetches data on each request, and the page is rendered on the server.



How to Create an API with Next.js?

Next.js allows you to create API routes under the /pages/api/ directory. Each file inside /api/ is an API endpoint that runs on the server.

Example of an API Route: 
  
    const products = [
      { id: 1, name: "Laptop" },
      { id: 2, name: "Phone" },
      { id: 3, name: "Tablet" },
    ];

    export async function GET() {
      return Response.json(
        products,
        { status: 200 }
      );
    }

    export async function POST(request) {
      try {
        const body = await request.json();

        if (!body.name) {
          return Response.json(
            { message: "Product name is required" },
            { status: 400 }
          ); // ❌ 400 Bad Request
        }

        const newProduct = {
          id: (Math.floor(Math.random() * 1001)),
          name: body.name
        };

        products.push(newProduct);

        return Response.json(
          newProduct,
          { status: 201 }
        ); // ✅ 201 Created
      } catch (error) {
        return Response.json(
          { message: "Internal Server Error" },
          { status: 500 }
        ); // ❌ 500 Server Error
      }
    }
