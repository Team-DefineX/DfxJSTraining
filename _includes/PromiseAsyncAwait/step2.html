Promise chaining is used to manage and process multiple asynchronous operations sequentially.

Each .then() block initiates the next operation based on the result of the previous one

Chaining Example:

Let's create a new Promise that represents an asynchronous operation that returns a text after 2 seconds: 

    
    const myPromise = new Promise((resolve, reject) => {
        setTimeout(() => {
            resolve('Hello, World!');
        }, 2000);
    });

Note that the setTimeout() function simulates an asynchronous operation.

we can call the .then() method using this Promise. The .then() method takes a callback function that will be executed when the Promise is resolved. In the example below, the callback is executed when the Promise is resolved, and it processes the result: 

    
    myPromise.then((result) => {
        console.log(result);
        return result.toUpperCase();
    });

This .then() method takes the result, prints it in uppercase, and returns the result in uppercase. Now, we can extend this Promise chaining example with the next step: 

    
    myPromise
        .then((result) => {
            console.log(result);
            return result.toUpperCase();
        })
        .then((result) => {
            console.log(result);
            return result.split('').reverse().join('');
        })
            .then((result) => {
            console.log(result);
        });

Output:

    
    "Hello, World!"
    "HELLO, WORLD!"
    "!DLROW ,OLLEH"
