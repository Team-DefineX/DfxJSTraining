Why Promises?

Promises are used in JavaScript to effectively manage and control asynchronous operations.

Promises are essential to prevent callback hell and write more organized code.

Basic Functionality of a Promise

A Promise is an object that will return in case of the successful completion or failure of an operation

It has three fundamental states:

  • Pending: The Promise is in an unfinished state.
  • Fulfilled: The Promise has been successfully completed.
  • Rejected: The Promise has been resulted in an error.

The fulfilled state indicates that the asynchronous operation was completed successfully:

The rejected state indicates that the asynchronous operation failed.

Creating a Promise

A Promise is created using the Promise class, which includes resolve and reject functions to initiate an operation and manage its result. 

    
    const myPromise = new Promise((resolve, reject) => {
        const success = true;
        
        if (success) {
            resolve('Successfully completed');
        } else {
            reject('An error occurred');
        }
    });

Once a new Promise object is created, its state is pending. If a promise reaches fulfilled or rejected state, it is resolved.

Consuming a Promise: then, catch, finally

The then() Method

.then(): Used to specify a function to execute when the Promise is successfully completed. 

    
    const myPromise = new Promise((resolve, reject) => {
        resolve('Successfully completed');
    });

    myPromise.then((message) => console.log('Result:', message));

The catch() Method

.catch(): Used to specify a function to execute when the Promise is rejected with an error. 

    
    const myPromise = new Promise((resolve, reject) => {
        const success = true;
        
        if (success) {
            resolve('Successfully completed');
        } else {
            reject('An error occurred');
        }
    });

    myPromise.catch((error) => console.error('Error:', error));

The finally() Method

.finally(): Used to specify a function to execute when the Promise is settled (either fulfilled or rejected), regardless of the outcome. 

    
    const myPromise = new Promise((resolve, reject) => {
        const success = true;
        
        if (success) {
            resolve('Successfully completed');
        } else {
            reject('An error occurred');
        }
    });

    myPromise
        .then((message) => console.log('Result:', message))
        .catch((error) => console.error('Error:', error))
        .finally(() => console.log('Operation completed.'));
