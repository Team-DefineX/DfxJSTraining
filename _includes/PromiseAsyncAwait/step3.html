Promise.all()

The Promise.all() method waits for all specified Promises to be fulfilled and returns an array of their results. If any Promise is rejected, Promise.all() catches the first error and rejects with that error.

Example

Let's make concurrent API calls from different sources and handle their results: 

    
    const promises = [
        fetch('https://api.example.com/endpoint1'),
        fetch('https://api.example.com/endpoint2'),
        fetch('https://api.example.com/endpoint3')
    ];
    
    Promise.all(promises)
        .then((responses) => {
            // All API calls completed
            return Promise.all(responses.map((response) => response.json()));
        })
        .then((data) => {
            console.log('All data:', data);
        })
        .catch((error) => {
            console.error('An error occurred:', error);
        });

Promise.race()

The Promise.race() method waits for any of the specified Promises to be fulfilled and returns the result of the first completed Promise.

Example

Let's say we want to fetch data from different sources and use the data from the first one that responds: 

    
    const fetchFromSource1 = fetch('https://api.example.com/source1');
    const fetchFromSource2 = fetch('https://api.example.com/source2');

    Promise.race([fetchFromSource1, fetchFromSource2])
        .then((firstResponse) => {
            // Use the result of the first completed one
            return firstResponse.json();
        })
        .then((data) => {
            console.log('First arrived data:', data);
        })
        .catch((error) => {
            console.error('An error occurred:', error);
        });

Promise.any()

The Promise.any() method waits for any of the specified Promises to be fulfilled and returns the result of the first completed Promise. If all Promises are rejected, it throws an AggregateError.

Example

Let's fetch data from different sources and use the data from the first one that responds: 

    
    const fetchFromSource1 = fetch('https://api.example.com/source1');
    const fetchFromSource2 = fetch('https://api.example.com/source2');
    
    Promise.any([fetchFromSource1, fetchFromSource2])
        .then((firstResponse) => {
            // Use the result of the first completed one
            return firstResponse.json();
        })
        .then((data) => {
            console.log('First arrived data:', data);
        })
        .catch((error) => {
            console.error('All promises were rejected:', error);
        });

Promise.allSettled()

The Promise.allSettled() method waits for all specified Promises to settle (either fulfilled or rejected) and returns an array with the outcome of each Promise, including errors.

Example

Let's fetch data from different sources and handle the results: 

    
    const fetchFromSource1 = fetch('https://api.example.com/source1');
    const fetchFromSource2 = fetch('https://api.example.com/source2');
    
    Promise.allSettled([fetchFromSource1, fetchFromSource2])
        .then((results) => {
            results.forEach((result, index) => {
                if (result.status === 'fulfilled') {
                    console.log(`Promise ${index + 1} succeeded:`, result.value);
                } else {
                    console.error(`Promise ${index + 1} failed:`, result.reason);
                }
            });
        });

Promise.finally()

The finally() method is used to specify a function to execute when the Promise chain is settled (either fulfilled or rejected).

Example

Let's send a notification when an operation is completed: 

    
    fetch('https://api.example.com/data')
        .then((response) => response.json())
        .then((data) => {
            console.log('Data received:', data);
        })
        .catch((error) => {
            console.error('An error occurred:', error);
        })
        .finally(() => {
            console.log('Operation completed.');
        });
