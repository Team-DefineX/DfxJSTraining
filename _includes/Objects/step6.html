Data and accessor properties are the two kinds of properties that are used for objects.


1) Data properties


A data property has a single location where a data value can be found. There are four attributes to a data property:


  •  Configurarable – determines if the delete operator can be used to remove or redefine a property.
  •  Enumerable – it lets you know whether a property may be brought back in a for...in loop.
  •  Writable – states that a property's value may be changed.
  •  Value – includes a property's true value.

All properties created directly on an object have their Configurable, Enumerable, and Writeable attributes set to true by default. The Value attribute has an undefined default value.


In the next example, a car object is made with three properties: 'Car Brand', headquartered and numberOfEmployees. The configurable, enumerable, and writable traits are all set to true. And their values are 'Volkswagen', 'Wolfsburg' and 5400: 

    
    let car = {
        'Car Brand': 'Volkswagen',
        headquartered: 'Wolfsburg',
        numberOfEmployee: 5400
    }

Use the Object.defineProperty() function to modify any property's attribute.


Three arguments are accepted by the Object.defineProperty() method:


  • An object.
  • A property name of the object.
  • A property descriptor object that has four properties: configurable, enumerable, writable, and value.

If you define an object's property using the Object.defineProperty() function, Configurable, Enumerable, and Writable are set to false by default unless you specify otherwise.


The car object in the example below has the 'Car Brand' property set: 

    
    let car = {};
    car['Car Brand'] = 'Volkswagen';

Because the Configurable attribute's default value is set to true, you can delete it as follows: 

    
    delete car['Car Brand'];
    
    console.log(car['Car Brand']); // undefined

Using the Object.defineProperty() function, the following example builds a car object and adds the numberOfEmployee property to it: 

    
    'use strict';
    
    let car = {};
    
    Object.defineProperty(car, 'numberOfEmployee', {
        configurable: false,
        value: 5400
    });
    
    delete car.numberOfEmployee; // TypeError: Cannot delete property 'numberOfEmployee' of #<Object>

In this instance, the Configurable attribute is false. Errors result from deleting the numberOfEmployees property.


In addition, you cannot change a non-configurable property to a Configurable one.


If you attempt to use the Object.defineProperty() method to modify any attribute other than the writable one, you will receive an error. or: 

    
    'use strict';
    
    let car = {};
    
    Object.defineProperty(car, 'numberOfEmployee', {
        configurable: false,
        value: 5400
    });
    
    
    Object.defineProperty(car, 'numberOfEmployee', { // TypeError: Cannot redefine property: numberOfEmployee
        configurable: true
    });

All the features of an object have the Enumerable attribute set to true by default. It suggests that you can use the for...in loop like this to go through all of an object's properties: 

    
    let car = {}

    car.headquartered = 'Wolfsburg'
    car.numberOfEmployee = 5400
    
    for (let property in car) { // "headquartered" "numberOfEmployee"
        console.log(property)
    }

The Enumerable attribute is set to false in the following to make the headquartered property non-enumerable: 

    
    let car = {}

    car.headquartered = 'Wolfsburg'
    car.numberOfEmployee = 5400
    
    Object.defineProperty(car, 'headquartered', {
        enumerable: false
    })
    
    for (let property in car) { // "numberOfEmployee"
        console.log(property);
    }

2) Accessor properties


Accessor properties contain Configurable and Enumerable qualities, just like data properties.


Instead of Value and Writable, the accessor properties have the Get and Set properties.


Get is automatically called to return a value when data is read from an accessor property. The Get function has an undefined default return value.


The Set function is automatically called if an accessor property is provided with a value.


Use the Object.defineProperty() method for defining an accessor property or as in: 

    
     let car = {
        'Car Brand': 'Volkswagen',
        headquartered: 'Wolfsburg',
        numberOfEmployee: 5400
    }
    
    Object.defineProperty(car, 'companyInfo', {
        get: function () {
            return this['Car Brand'] + ' headquartered is ' + this.headquartered + 'and has ' + this.numberOfEmployee + ' employee'
        },
        set: function (value) {
            let parts = value.split(' ');
            if (parts.length == 3) {
                this['Car Brand'] = parts[0]
                this.headquartered = parts[1]
                this.numberOfEmployee = parts[2]
            } else {
                throw 'Invalid name format';
            }
        }
    })
    
    console.log(car.companyInfo) // "Volkswagen headquartered is Wolfsburgand has 5400 employee"

    car.companyInfo = "Mercedes Stuttgart 6000"
		
    console.log(car.companyInfo) // "Mercedes headquartered is Stuttgart has 6000 employee"
Define multiple properties: Object.defineProperties()

Using the Object.defineProperties() method in ES5, you can define several properties in a single sentence, or you can: 

    
    var car = {}
    
    Object.defineProperties(car, {
        'Car Brand': {
            value: 'Volkswagen'
        },
        headquartered: {
            value: 'Wolfsburg'
        },
        numberOfEmployee: {
            value: 5400
        },
        companyInfo: {
            get: function () {
                return `${this['Car Brand']} headquartered is ${this.headquartered} has ${this.numberOfEmployee} employee`
            }
        }
    })
    
    console.log(car.companyInfo); // "Volkswagen headquartered is Wolfsburg has 5400 employee"

In this example, the car object has three data properties: 'Car Brand', headquartered and numberOfEmployee as well as one accessor property called companyInfo.


JavaScript object property descriptor


You can get the descriptor object for a property using the Object.getOwnPropertyDescriptor() function. This method requires two arguments:


  • An object
  • A property of the object

It returns an object descriptor that describes a property. Configurable, Enumerable, Writable, and Value are the four properties of the descriptor object.


Next example gathers the descriptor object of the car object's 'Car Brand' property from the previous example. 

    
    let car = {
        'Car Brand': 'Volkswagen',
    };
    
    let descriptor = Object.getOwnPropertyDescriptor(car, 'Car Brand');
    
    console.log(descriptor);

Output: 

    
    {
        configurable: true,
        enumerable: true,
        value: "Volkswagen",
        writable: true
    }
