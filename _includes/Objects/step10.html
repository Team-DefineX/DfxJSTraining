Arrow functions are a clear and concise way to write regular Javascript functions in a more precise and shorter manner. In version ES6, arrow functions were introduced. They improve the structure and readability of our code.


Arrow functions are anonymous functions, which lack a name and are not associated with an identifier. Arrow functions do not return a value and can be declared without the keyword function. They are also referred to as Lambda Functions.


It appears as follows: 

    
    let func = (arg1, arg2, ..., argN) => expression;

This creates a function named func that accepts the arguments arg1..argN, then evaluates the expression on the right using those arguments and returns the result.


In other terms, it is the shorter version of: 

    
    let func = function(arg1, arg2, ..., argN) {
        return expression;
    };

Let’s see an example: 

    
    let multiply = (x, y) => x + y;
    /* This arrow function is a shorter form of:
    
    let multiply = function(x, y) {
      return x + y;
    };
    */
    
    alert(multiply(4, 5)); // 20

As you can see, a function that takes the two inputs x and y is denoted by (x, y) => x * y. It evaluates the expression x * y during execution and returns the outcome.


#1 If there is only one argument, the parentheses surrounding parameters can be omitted, making the code even shorter.


For instance: 

    
    let divideIntoTwo = x => x / 2;
    // roughly the same as: let divideIntoTwo = function(x) { return x / 2 }
    
    alert(divideIntoTwo(10)); // 5

#2 If there are no arguments, the parentheses must be empty but present: 

    
    let welcomeMessage = () => alert("Welcome to Definex Javascript Training!");
    
    welcomeMessage(); // Welcome to Definex Javascript Training!

Arrow functions can be applied similarly to Function Expressions.


For example, to create a function dynamically: 

    
    let yourAge = 18;
    
    let accessControlPoint = (yourAge < 18) ?
      () => alert('Children Are Not Allowed!') :
      () => alert("Go Into!");
    
      accessControlPoint(); // Go Into!

Multiline arrow functions

The arrow functions we've seen until now have been basic. They evaluated the left-side arguments and returned the right-side expression with them.


From time to time, we require a complex function with multiple expressions and statements. Then we can surround them in curly braces. Similar to regular functions, curly braces require a return statement to return a value. 

 
    
    let pow = (x, y) => {  // the curly brace opens a multiline function
        let result = x ** y;
        return result; // if we use curly braces, then we need an explicit "return"
    };
      
    alert(pow(8, 2)); // 64

Advantages of Arrow functions:

  • Arrow functions decrease the amount of code.
  • Single-line functions may omit the return statement and functional braces.
  • It improves the code's readability.
  • Arrow functions offer lexical this binding, which allows them to take the value of this from the scope in which they are used. When working with event listeners or callback functions, where the value of this can be unclear, this feature can be helpful.

Disadvantage of Arrow functions:

  • There is no prototype property for arrow functions.
  • Using the new keyword with arrow functions is not permitted.
  • It is not possible to utilize arrow functions as constructors.
  • These methods are anonymous, which makes it difficult to debug the code.
