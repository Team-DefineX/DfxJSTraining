An object is a collection of key/value pairs or properties. When the value is a function, the property becomes a method. Typically, you use methods to describe the object behaviors.


For example, the following adds the firstMethod method to the car object: 

    
    let car = {
        'Car Brand': 'Volkswagen',
        hasElectricModels: true,
        headquartered: 'Wolfsburg',
        numberOfEmployee: 5400
    }
    
    function firstMethod() {
        console.log('This is our first method')
    }
    
    car.firstMethod = firstMethod
    
    car.firstMethod() // This is our first method

In this example:


  • First, use a function expression to define a function and assign it to the firstMethod property of the car object.
  • Then, call the method firstMethod() method.

Besides using a function expression, you can define a function and assign it to an object like this: 

    
    let car = {
        'Car Brand': 'Volkswagen',
        hasElectricModels: true,
        headquartered: 'Wolfsburg',
        numberOfEmployee: 5400
    }
    
    function firstMethod() {
        console.log('This is our first method')
    }
    
    car.firstMethod = firstMethod
    
    car.firstMethod()

In this example:


  • First, define the firstMethod() function as a regular function.
  • Second, assign the function name to the the firstMethod property of the car object.
  • Third, call the firstMethod() method.

Object method shorthand

JavaScript allows you to define methods of an object using the object literal syntax as shown in the following example: 

    
    let car = {
        'Car Brand': 'Volkswagen',
        hasElectricModels: true,
        headquartered: 'Wolfsburg',
        numberOfEmployee: 5400,
        firstMethod() {
            console.log('This is our first method')
        }
    }

ES6 provides you with the concise method syntax that allows you to define a method for an object: 

    
    let car = {
        'Car Brand': 'Volkswagen',
        hasElectricModels: true,
        headquartered: 'Wolfsburg',
        numberOfEmployee: 5400,
        firstMethod() {
            console.log('This is our first method')
        }
    }
    
    car.firstMethod()

The this value

Typically, methods need to access other properties of the object.


For example, you may want to define a method that returns the headquartered and numberOfEmployee values of the car object.


Inside a method, the this value references the object that invokes the method. Therefore, you can access a property using the this value as follows: 

    
    this.propertyName

The following example uses the this value in the companyInfo() method: 

    
    let car = {
        'Car Brand': 'Volkswagen',
        hasElectricModels: true,
        headquartered: 'Wolfsburg',
        numberOfEmployee: 5400,
        firstMethod() {
            console.log('This is our first method')
        },
        companyInfo() {
            return `${this['Car Brand']} headquartered is ${this.headquartered}`
        }
    }
    
    console.log(car.companyInfo()) // "Volkswagen headquartered is Wolfsburg"
