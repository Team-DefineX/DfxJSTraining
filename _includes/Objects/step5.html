Objects are collections of key-value pairs or properties. The property becomes a method when its value is a function. Methods are typically used to define the behaviors of objects.


For instance, the code below adds the firstMethod method to the car object: 

    
    let car = {
        'Car Brand': 'Volkswagen',
        hasElectricModels: true,
        headquartered: 'Wolfsburg',
        numberOfEmployee: 5400
    }
    
    function firstMethod() {
        console.log('This is our first method')
    }
    
    car.firstMethod = firstMethod
    
    car.firstMethod() // This is our first method

In this example:


  • First, define a function using a function expression and assign it to the firstMethod property of the car object.
  • Afterwards, call the firstMethod() method.

A function can also be defined and assigned to an object using a function expression, as in the following example: 

    
    let car = {
        'Car Brand': 'Volkswagen',
        hasElectricModels: true,
        headquartered: 'Wolfsburg',
        numberOfEmployee: 5400
    }
    
    function firstMethod() {
        console.log('This is our first method')
    }
    
    car.firstMethod = firstMethod
    
    car.firstMethod()

In this example:


  • Firstly, define firstMethod() as a regular function.
  • Secondly, assign the function's name to the car object's firstMethod property.
  • Finally, call the firstMethod() method.

Object method shorthand

The following example demonstrates how you can define an object's methods using the object literal syntax in JavaScript: 

    
    let car = {
        'Car Brand': 'Volkswagen',
        hasElectricModels: true,
        headquartered: 'Wolfsburg',
        numberOfEmployee: 5400,
        firstMethod() {
            console.log('This is our first method')
        }
    }

ES6 offers a concise method syntax for defining object methods: 

    
    let car = {
        'Car Brand': 'Volkswagen',
        hasElectricModels: true,
        headquartered: 'Wolfsburg',
        numberOfEmployee: 5400,
        firstMethod() {
            console.log('This is our first method')
        }
    }
    
    car.firstMethod()

The this value

Methods frequently need to access additional object properties.


For instance, you might wish to create a method that gathers the car object's headquarters and numberOfEmployee properties.


The this value in a method refers to the object that called the method. As a result, the following shows how you can access a property using this value: 

    
    this.propertyName

The following example uses the this value in the companyInfo() method: 

    
    let car = {
        'Car Brand': 'Volkswagen',
        hasElectricModels: true,
        headquartered: 'Wolfsburg',
        numberOfEmployee: 5400,
        firstMethod() {
            console.log('This is our first method')
        },
        companyInfo() {
            return `${this['Car Brand']} headquartered is ${this.headquartered}`
        }
    }
    
    console.log(car.companyInfo()) // "Volkswagen headquartered is Wolfsburg"
