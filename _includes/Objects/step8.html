This lesson will cover the JavaScript keyword this and how its value is assigned in different scenarios.


In JavaScript, objects serve as the fundamental building elements. this object is the only special object accessible in JavaScript. The value of this variable is displayed at each line of JavaScript execution. The value of this depends on how the code is being run.


“this” Refers to a Global Object

The execution context for an execution is, by default, global. Therefore, if code is being run as part of a simple function call, this refers to a global object.


For the browser, the global object is the window object. So, the value of this will be a special object called global in a NodeJS environment.


For example: 

    
    function myFunc () {
        console.log(this === window); 
    }
    
    myFunc();	// true
    console.log(this === window) // true

Immediately Invoked Function Expression (IIFE) 

    
    (function(){
        console.log("Anonymous function invocation");
        console.log(this === window); // true
    })();

If strict mode is enabled for any function, the value of this will be marked as undefined. Instead of the windows object, the global object refers to undefined. 


    
    function myFunc () {
        'use strict';
        console.log(this === window); 
    }
    
    myFunc();	//prints false on console as in “strict mode” value of “this” in global execution context is undefined.

myFunc prints false into the console since, in strict mode, the value of this in a global-execution context is undefined.


“this” Refers to a New Instance

A function is referred to as a constructor function and returns a new instance when it is called with the new keyword. The value of this in such circumstances corresponds to a newly formed instance. 


    
    function Car(brand, headquartered) {
        this.brand = brand;
        this.headquartered = headquartered;
    
        this.companyInfo = function() {
            console.log(`${this.brand} headquartered is ${this.headquartered}`);
        }
    }
    
    let car = new Car("Volkswagen", "Wolfsburg");
    car.companyInfo();  // Volkswagen headquartered is Wolfsburg
    let car2 = new Car("Mercedes", "Stuttgart");
    car2.companyInfo();  // "Mercedes headquartered is Stuttgart"

In the case of car.companyInfo, this refers to a new instance of car, whereas car2.companyInfo() refers to car2 (a different instance from car).


“this” Refers to an Invoker Object (Parent Object)

A method or simple value can serve as an object's property in JavaScript. this refers to the object that holds the method that is being called when an object's method is called.


The method myFunc from the first example will be used in this one. 

    
    function companyInfo () {
        console.log(this === window); 
    }
    
    let car = {
        numberOfEmployee: 5400,
        companyInfo: companyInfo,
        companyInfo1: function() {
            console.log(this === window);
        }
    }
    
    car.companyInfo()  // Prints false because now “this” refers to user object instead of global object.
    let companyInfo1 = car.companyInfo1;
    companyInfo1() // Prints true as this method is invoked as a simple function.
    car.companyInfo1()  // Prints false on console as companyInfo1 is invoked as a object’s method

Since the reference of this is now to the car object rather than the global object, the call to car.companyInfo returns false.


companyInfo1 has the the same function description, but when it is called using a basic function call, a global object is referenced. Furthermore, this relates to the parent object when the same definition is used in an object's method. Thus, how a method is called determines the value of this.


“this” With the Call and Apply Methods

In JavaScript, a function is a particular kind of object. There are call, bind, and apply methods in every function. In the context of the function's execution, this can be given a specific value using these techniques.


We'll use the second example outlined above to clarify how to use call: 

    
    function Car(brand, headquartered) {
        this.brand = brand;
        this.headquartered = headquartered;
    
        this.companyInfo = function() {
            console.log(`${this.brand} headquartered is ${this.headquartered}`);
        }
    }
    
    let car = new Car("Volkswagen", "Wolfsburg");
    car.companyInfo();  // Volkswagen headquartered is Wolfsburg
    let car2 = new Car("Mercedes", "Stuttgart");
    car2.companyInfo();  // "Mercedes headquartered is Stuttgart"
    
    car.companyInfo.call(car2); // Here we are setting value of this to be car2 object
    // Prints "Mercedes headquartered is Stuttgart"

The method by which an argument is given is the only distinction between the call and apply methods. The second argument for the apply method is an array of arguments, whereas the arguments are supplied separately for the call function.


“this” With the Bind Method

The bind method returns a new method with this referencing the first given argument. We will use the preceding example to show the bind method. 

    
    function Car(brand, headquartered) {
        this.brand = brand;
        this.headquartered = headquartered;
    
        this.companyInfo = function() {
            console.log(`${this.brand} headquartered is ${this.headquartered}`);
        }
    }
    
    let car = new Car("Volkswagen", "Wolfsburg");
    car.companyInfo();  // Volkswagen headquartered is Wolfsburg
    let car2 = new Car("Mercedes", "Stuttgart");
    car2.companyInfo();  // "Mercedes headquartered is Stuttgart"

    let car2Display = car.companyInfo.bind(car2);  // Creates new function with value of “this” equals to car2 object
    car2Display(); // "Mercedes headquartered is Stuttgart"

“this” With the Arrow Function

A new concept called arrow function was introduced by ES6. JavaScript sets this lexically in arrow functions.


This indicates that the arrow function inherits the execution context from the outer function where it is defined rather than creating its own. See the example below: 

    
    let getThis = () => this;
    console.log(getThis() === window); // true

This example sets the global object, or window in the web browser, as the value for this.


Using an arrow function while constructing a method will result in a problem because it lacks the ability to create its own execution context. For instance: 

    
    function Car() {
        this.brand = 'Volkswagen';    
    }

    Car.prototype.getheadquartered = () => {
      return this.headquartered;
    };
      
    var car = new Car();
    console.log(car.getheadquartered()); // undefined

The value of this within the getheadquartered method refers to the global object, not the Car object, but the global object has no headquartered property. Therefore, this.headquartered returns undefined in the getheadquartered method.
