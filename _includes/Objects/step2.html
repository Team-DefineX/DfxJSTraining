There are 3 ways to create objects:


  1. By object literal
  2. By creating instance of Object directly (using new keyword)
  3. By using an object constructor (using new keyword)

1) JavaScript Object by object literal

Objects can be put in variables just like any other type in JavaScript. Curly braces {} are used to mark an object literal: 

    
    let company = {}; // company is an empty object

We fill an object with unordered data. This data is organized into key-value pairs. A key is like a variable name that points to a location in memory that holds a value.



We insert unordered data into an object. Key-value pairs are used to organize this data. A key is similar to a variable name that points to a place in memory where a value is stored.


The value of a key can be any language-supported data type, including functions and other objects.


The name of the key, or identifier, is followed by a colon and then the value. In an object literal, each key-value pair is separated by a comma (,). Keys are strings, but JavaScript permits us to omit the quotation marks when a key contains no special characters. 


    
    // An object literal with two key-value pairs
    let car = {
        'Car Brand': 'Volkswagen',
        numberOfEmployee: 5400,
        headquartered: 'Wolfsburg' 
    };

There are three properties on the car object: 'numberOfEmployee', 'Car Brand', and 'headquartered'. Because 'Car Brand' contains a space character, it is enclosed in quotation marks.



2) By creating instance of Object

The following is the syntax for generating an object directly: 

    
    var car = new Object();

Here, new keyword is used to create the object. 

    
    var car = new Object();  
    car.carBrand = 'Volkswagen';
    car.numberOfEmployee = 5400;
    car.headquartered = 'Wolfsburg';

    console.log(car);

3) By using an Object constructor

In this case, you need to develop a function with arguments. Using this keyword, you can attribute each argument's value to the current object.


This keyword refers to the current object.


The following is an example of creating an object using an object constructor: 

    
    function car(carBrand, numberOfEmployee, headquartered){  
        this.carBrand = carBrand;  
        this.numberOfEmployee = numberOfEmployee;  
        this.headquartered = headquartered;  
    }

    let car1 = new car('Volkswagen', 5400, 'Wolfsburg');  
      
    console.log(car1);
