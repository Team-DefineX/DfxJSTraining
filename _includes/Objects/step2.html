There are 3 ways to create objects.


  1. By object literal
  2. By creating instance of Object directly (using new keyword)
  3. By using an object constructor (using new keyword)

1) JavaScript Object by object literal

Objects can be assigned to variables just like any JavaScript type. We use curly braces, {}, to designate an object literal: 

    
    let car = {}; // company is an empty object

We fill an object with unordered data. This data is organized into key-value pairs. A key is like a variable name that points to a location in memory that holds a value.



A key’s value can be of any data type in the language including functions or other objects.


We make a key-value pair by writing the key’s name, or identifier, followed by a colon and then the value. We separate each key-value pair in an object literal with a comma (,). Keys are strings, but when we have a key that does not have any special characters in it, JavaScript allows us to omit the quotation marks: 



    
    // An object literal with two key-value pairs
    let car = {
        'Car Brand': 'Volkswagen',
        numberOfEmployee: 5400,
        headquartered: 'Wolfsburg' 
    };

The car object has three properties 'Car Brand', 'numberOfEmployee' and headquartered. 'Car Brand' has quotation marks because it contains a space character.



2) By creating instance of Object

The syntax of creating object directly is given below: 

    
    var car = new Object();

Here, new keyword is used to create object.


Let’s see the example of creating object directly. 

    
    var car = new Object();  
    car.carBrand = 'Volkswagen';
    car.numberOfEmployee = 5400;
    car.headquartered = 'Wolfsburg';

    console.log(car);

3) By using an Object constructor

Here, you need to create function with arguments. Each argument value can be assigned in the current object by using this keyword.


The this keyword refers to the current object.


The example of creating object by object constructor is given below. 

    
    function car(carBrand, numberOfEmployee, headquartered){  
        this.carBrand = carBrand;  
        this.numberOfEmployee = numberOfEmployee;  
        this.headquartered = headquartered;  
    }

    let car1 = new car('Volkswagen', 5400, 'Wolfsburg');  
      
    console.log(car1);
