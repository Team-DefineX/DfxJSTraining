Bracket notation is the second method of gaining access to a key's value [].


Indexing an array is possible using bracket notation: 

    
    ['Driven By Impact', 'Best Enviroment for Best People', 'Future in Mind', 'Define Next'][0]; // Returns 'Driven By Impact'

The property name (key) is passed in as a string in order to access an object's property using bracket notation.


When using keys that contain numbers, spaces, or other special characters, we must write them in bracket notation. In these cases, our code would throw an error if bracket notation wasn’t used. 

    
    let car = {
        'Car Brand': 'Volkswagen',
        hasElectricModels: true,
        headquartered: 'Wolfsburg',
        numberOfEmployee: 5400
      };

      car['Car Brand'];           // Returns 'Volkswagen'
      car['hasElectricModels'];   // Returns true
      car[headquartered];         // Returns  'Wolfsburg'
      car['numberOfEmployee'];    // Returns 5400
      car['COE'];                 // Returns undefined
