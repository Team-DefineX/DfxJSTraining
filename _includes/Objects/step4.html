The second way to access a key’s value is by using bracket notation, [ ].


You’ve used bracket notation when indexing an array: 

    
    ['Driven By Impact', 'Best Enviroment for Best People', 'Future in Mind', 'Define Next'][0]; // Returns 'Driven By Impact'

To use bracket notation to access an object’s property, we pass in the property name (key) as a string.


We must use bracket notation when accessing keys that have numbers, spaces, or special characters in them. Without bracket notation in these situations, our code would throw an error. 

    
    let car = {
        'Car Brand': 'Volkswagen',
        hasElectricModels: true,
        headquartered: 'Wolfsburg',
        numberOfEmployee: 5400
      };

      car['Car Brand'];           // Returns 'Volkswagen'
      car['hasElectricModels'];   // Returns true
      car[headquartered];         // Returns  'Wolfsburg'
      car['numberOfEmployee'];    // Returns 5400
      car['COE'];                 // Returns undefined
