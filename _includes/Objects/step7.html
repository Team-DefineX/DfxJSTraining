In application code, objects are often nested— an object might have another object as a property which in turn could have a property that’s an array of even more objects!


In our car object, we want a employees object. This will contain all employees who do work on the company. Each of those employees are objects themselves. They have properties like name, surname and level, and they each have unique methods based on their informations. We can also nest other objects in the car such as a administration department object.

We can chain operators to access nested properties. We’ll have to pay attention to which operator makes sense to use in each layer. 

    
    car.employees.employee1.employeeInfo() // Returns 'Gökhan Ertaş as a Team Leader, manages the teams'

In the preceding code:


  • First the computer evaluates car.employees, which results in an object containing the employee1, employee2, employee3 and employee4 objects.
  • We accessed the employee1 object by appending employeeInfo.
  • The employeeInfo function return name, surname, and level which returned the value stored there: 'Gökhan Ertaş as a Team Leader, manages the teams'
