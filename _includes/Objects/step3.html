There are two methods to access a property of an object. Let's check out the dot (.) notation method first:


You can access the methods and properties of the built-in objects and data instances using dot (.) notation: 

    
    'Volkswagen'.length; // Returns 10

When using property dot notation, the object's name is written first, then the dot operator, followed by the property name (key): 

    
    let car = {
        'Car Brand': 'Volkswagen',
        numberOfEmployee: 5400
    };

    car['Car Brand'];       // Returns 'Volkswagen'
    car.numberOfEmployee;   // Returns 5400

Undefined will be returned if we attempt to access a property on the object that does not exist. 

    
    car.Headquartered; // Returns undefined
